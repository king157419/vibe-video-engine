- 成片：`lab01_fable.mp4`（1920×1080，30fps，H.264，61.9 s = 60.4 s 旁白 + 1.5 s 停留）
- 印样：`lab01_fable_印样.png`（每秒一帧，6 列）

## 1. 设计系统

**一张纸、一支笔、一种颜色。** 整集是同一张大纸（世界画布，约 3700×1100），摄像机在纸上平移缩放；每一样东西都被一支铅笔当着观众的面画出来，画过的东西留在纸上，最后拉远能看到整段思路。

| 项 | 规则 |
|---|---|
| 配色 | 纸 `#FAF8F2`（Python 合成的纸纹 + 暗角）；主墨 `#2F2A26`；次墨 `#6A645C`（辅线、备注）；铅笔灰 `#C2BBAF`；**唯一强调色琥珀 `#E9A93A` / `#D48F1E`**。琥珀只给三样东西：火、「需要」、关键词划线。观众看到琥珀就知道「这是底层在起作用」 |
| 字体 | 画面里的**关键词用真实笔顺写出来**（hanzi-writer-data 的楷体轮廓 + 中线，Arphic 许可）：事情 / 你的反应 / 需要 / 半小时。其余画面文字用 Noto Serif SC（逐字擦出、每字随机歪 ±3°）；底部阅读字幕用 Noto Sans SC 700，46px，一次只显示正在念的一行，逐字由灰变墨，关键词底下画一道琥珀手绘线。没有下载新字体（本轮不联网），要更「手写」可换霞鹜文楷，位置在 `theme.ts` 一处 |
| 线条 | roughjs 只用来**算形状**（固定 seed），我把它的路径拆成折线，逐帧只画前 p%，所以每条线都是「一笔一笔画出来的」，且笔尖位置可知；画完后在 2 版抖动之间每 9 帧切一次（线条「呼吸」）。三档线宽：主线 4 / 细线 2.6 / 发丝 1.8；琥珀强调用 perfect-freehand 生成**有轻重的马克笔迹**（模拟压力、起收笔收尖）。填充一律用 roughjs 排线（hachure），从左往右像马克笔涂过去，不用色块 |
| 笔 | 一支铅笔跟着当前正在画的那条线走（`penAt`），线与线之间滑过去，停笔时抬起淡出；同时带一条循环的铅笔沙沙声（numpy 合成），音量跟着「是否在画」 |
| 镜头 | 关键帧式摄像机（`camera.ts`），缩放走对数插值，全程叠一层很轻的手持漂移；「火上来了」那一秒加抖动。规则：**每一段旁白换一个镜头状态**——故事区全景 → 推近朋友圈 → 拉开看火 → 平移到三层图 → 逐层推近（上/中/下）→ 略拉开看「需要」→ 换人换工作时看整张图 → 结尾拉远看整张纸。13 个关键帧，最长静止 6 s |
| 运动 | 全部由 `useCurrentFrame` 驱动，无 CSS 动画、无 `Math.random`。动作都锚在逐字时间上：`cueAt(captions, 行, "词")` 取到那个字开口的毫秒，画面在那一刻起笔。起笔用 `bezier(0.42,0,0.3,1)`（起笔慢、收笔减速），淡入 `easeOut`，「被念到时」用一个 0→1→0 的 bump |

## 2. 视觉母题：三层图 + 琥珀

- **三层图**是整季的母题：事情 / 你的反应 / 需要，底层永远是琥珀排线。这一集只是「画出这张图」；后面的集数可以：
  - 换上面两层的内容（本集已演示：气泡时钟 → 人 → 公文包，底层不变），每期一个新故事塞进同一张图；
  - 往底层加新的需要（安全感、被看见、自主……），每期在「需要」那格写下一个新词，季末底层排成一排；
  - 从底层往上画箭头（本集的「起作用」箭头）讲「需要如何驱动反应」，反过来画讲「怎么照顾需要」；
  - 「火」是需要没被照顾的信号，可以在任何集数从右上角再冒一次（本集的 pop）。
- 琥珀 = 需要。全季只要看到琥珀就是在说底层。
- 笔和纸是恒定的「讲述者」；后面若要加「小人」，小人也应该是这支笔画出来的简笔人，而不是贴上去的插画。

## 3. 场景词汇表（`parts.tsx` 的动词 + `scenes.tsx` 的场景）

底层动词（可复用，全部纯函数/无状态组件，输入当前 `ms`）：

| 动词 | 组件 / 函数 | 输入 | 说明 |
|---|---|---|---|
| 画 Draw | `Ink({geo, p, vi, color, width, dash})` | roughjs 生成的 `Geo`、进度 p | 一笔一笔描出来；`R.circle/rect/line/curve/path/...` 生成 Geo，`variants()` 生成抖动版本 |
| 写 Write | `writeText(text, x, yTop, size, t0, dur, anchor)` → `Written({w, ms, color})` | 关键词、位置、字高、起止 | 真实笔顺，每笔时长按中线长度分配，字间停 90 ms；中线描边做 `<mask>`，用 `@remotion/paths` 的 `evolvePath` 推进。需要的字在 `hanzi.ts`（由 `make_hanzi` 脚本从 hanzi-writer-data 抽出） |
| 手写一句 Hand | `HandText({text, x, y, size, t0, dur, family, wobble})` | 长一点的句子 | 字体文字逐字用 clipPath 擦出，字有轻微歪斜；笔顺不重要的地方用它 |
| 马克笔 Marker | `markerRect / markerEllipse / markerLine(...)` → `Marker({m, p, color, size})` | 几何 + 进度 | perfect-freehand，`simulatePressure`，按进度截取点列；用于圈、下划线、删除线、结尾描三层 |
| 涂 Hatch | `Hatch({d, p, box, color, angle})` | roughjs 排线路径、进度、包围盒 | 用旋转的 clip 矩形让排线从一侧涂过去 |
| 计数 Count | `zhengStrokes(x, y, s)` | 位置、边长 | 「正」字五笔，每笔单独排时间，「看了几次」就画几笔 |
| 笔 Pen | `penAt(ms, strokes)` + `Pencil` | 所有登记过的笔画 | 自动跟随、滑动、抬笔 |
| 镜头 Camera | `camAt(ms, keys)` + `drift` | 关键帧 `{t, dur, cx, cy, s}` | 平移缩放 + 漂移/抖动 |
| 常用形 | `bubbleD / roundRectD / heartD / flamePts / arrowGeos / scribbleGeo` | 尺寸 | 气泡、圆角矩形、心、火苗、箭头、「假手写」波浪线 |

场景（`scenes.tsx`，都只读 `board` 数据 + `ms`）：

| 场景 | 承载的句子 | 参数（在 `board.ts` 里） |
|---|---|---|
| `Phone` | 发消息 / 在忙吗 / 没回 / 点开朋友圈 / 十分钟前点赞 | 手机位置尺寸、气泡列表、朋友圈条目、时间戳、心、圈 |
| `Clock` | 半小时没回 / 还是没回 | 圆心半径、两次扫针的起止 |
| `Tally` | 看了一眼、又看一眼 | 「正」的位置、每笔时刻 |
| `Fire` | 火上来了 / 别急着评理（变暗） | 火的位置尺寸、填充时刻、变暗时刻 |
| `Bridge` | 拆成三层看 | 弧线箭头两端 |
| `Stack` | 三层图全部：逐层描粗、写标签、层内小图、底层排线、上箭头、需要圈、换人换工作、再冒出来、结尾描三层 | 三层的位置、每个内容项的时刻 |
| `Dont` | 别想太多（被划掉） | 气泡位置、划掉时刻 |

## 4. 从任意稿子到 10 分钟：流水线

```
script.txt ──TTS/真声──▶ captions.json（逐字时间）
                              │
  节拍表 beats（人审）──────────┤   每句：动词 + 对象 + 锚定的字 + 画在纸的哪个格子
                              ▼
                     board.ts（分镜数据）     时刻全部用 cueAt(行, 词) 取，坐标用世界坐标
                              ▼
                     scenes.tsx（场景组件）   只读数据 + ms，逐帧插值
                              ▼
                     camera keys（镜头）      每段一个状态
                              ▼
                 渲染 → 印样 → 挑毛病 → 改 board → 局部重渲
```

- **每期都要重做的**：节拍表（每句配什么画面）、`board.ts` 里的时刻表 `T` 和坐标、镜头关键帧、几张新的「专用画面」（这期是手机/时钟/火，下期可能是餐桌/日历/账单）。
- **每期不用动的**：动词库、笔、纸、字幕、镜头引擎、三层图组件（换内容即可）、Write 的字库（新关键词跑一次脚本加进 `hanzi.ts`）。
- **10 分钟怎么撑**：一张纸横向分「岛」，每个段落一个岛（约 2000 px 宽），讲完平移到下一岛，每个岛内再推近 2–3 次；已画的都留着，每个段落结束时可以拉远回顾。三层图是常驻岛，每段结束都回来往图里添一笔。按本集的密度，每 10–20 s 一个新画面状态，10 分钟约 40 个画面动作，节拍表先写、再挑 4 张关键帧确认，再写数据。
- **下一步该自动化的**：节拍表 → `board.ts` 目前还是手写；可以先把节拍表做成 JSON（`{line, word, verb, args, cell}`），用 6×6 锚点格子代替像素坐标，渲染前自动检查重叠和字幕区侵入；再把 Stack/Phone 这类场景改成从 JSON 实例化。

## 5. 自评

**做得好的**
- 每一句都有专门画面，动作贴着字开口：半小时→针扫半圈；看一眼→「正」添一笔；十分钟前→时间戳；点赞→心+圈；火→火苗从右边升起并抖镜；三层→逐层描粗、逐层推近；换人换工作→上两层滑走换掉、底层不动；再冒出来→右上角小火苗；别想太多→写出来再划掉；结尾拉远把整张纸看一遍。
- 手绘感是真的：所有线一笔一笔画，笔在画面里，关键词按真实笔顺写，琥珀笔迹有轻重，线条在呼吸，有沙沙声。
- 只有一个强调色，画面干净，字幕清楚不挡画。

**还不够的**
- 「拿起手机看了一眼、放下、又看一眼」只有手机倾斜 + 「正」添笔，动作偏小，第二次看和第一次差别不明显。
- 三层图里的小图（气泡、时钟、放大镜）尺寸偏小，在 1.32× 推近时才够看；换人换工作的「人」和「公文包」很简。
- 结尾拉远时琥珀描三层在画面里偏小，「一层一层画清楚」的力度不够；可以在拉远前先描完，再拉远。
- 没有小人这个母题；「你」在画面里只以手机和「正」出现。
- 字体：关键词是楷体笔顺，其余是思源宋，两者放在一起还算协调，但比霞鹜文楷或小赖更工整；下一轮把手写句子换成 OFL 手写体。

**下一步最该改**
1. 把「看一眼 / 放下 / 又看一眼」做成真正的三拍：手机抬起→屏幕亮→放下→再抬起，「正」从 1 笔到 2 笔时旁边写「第 2 次」。
2. 节拍表 JSON 化 + 6×6 锚点，让下一期只改数据不改组件。
3. 加一个用同一支笔画出来的简笔小人，作为「你」的母题，在三层图旁边站着，需要被照顾到时表情变化。
