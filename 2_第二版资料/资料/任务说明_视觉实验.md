# 任务：做一个 60 秒的横屏「边讲边画」手绘讲解样片

## 背景

用户在做心理书讲解号，每期 8–12 分钟，自己口播，画面是手绘讲解。第一版做了五种竖屏样式，用户的评价：

> 视频效果做的也平平无奇……手绘框架的风格还是不错的，还算是讨喜。

用户心目中的好作品是电子智人的《信息论 惊奇之学》，拆解见 `D:\desk\claudex\24\2_第二版资料\资料\参考片拆解_电子智人.md`，一定要先读。它的核心是：**每一句话都有专门为它设计的动态演示，画面本身在讲内容**，而不是「模板背景 + 字幕」。我们要的是这种水准，只不过风格是手绘。

第一版的手绘样式在 `video-engine/src/styles/Sketch.tsx` 和 `video-engine/src/styles/sketch/`（竖屏 1080×1920，roughjs 画线）。它的问题是整期只有一张固定的五种需要关系图，外加字幕，画面没有跟着内容讲故事。可以借它的代码（复制到你自己的目录再改），但不要改原文件。

## 输入

- `video-engine/public/episodes/lab01/script.txt`：60 秒旁白稿。
- `video-engine/public/episodes/lab01/audio.mp3`：占位配音。
- `video-engine/public/episodes/lab01/captions.json`：逐字时间。结构是 `lines[].chars[]`，每个字带 `{t, s, e, hl}`，时间单位毫秒，`hl` 表示关键词。

稿子讲的是：发消息对方半小时没回 → 反复看手机、追问、翻朋友圈发现他刚给别人点赞 → 火上来了。然后把这件事拆成三层：**事情**（他回得慢）、**你的反应**（反复看、追问、找证据）、**需要**（想确认我在他那儿是重要的）。需要没照顾到，换个人、换份工作，它会换个样子再冒出来。最后预告：这期把三层一层层画清楚。

## 规格

- 1920×1080，16:9 横屏，30fps，H.264，带音频，时长跟音频走（约 60 秒，结尾可留 1–2 秒）。
- 这是 10 分钟长视频里的一段，设计要能撑得住 10 分钟：观众不能看腻，每 10–20 秒画面要有新状态。
- 字幕放在底部，是长视频的阅读字幕，要清楚好读，不能挡住画面；关键词可以强调。

## 画面要求

1. **每一组句子都有自己的手绘画面，而且画面承载意思**。比如：手机和聊天气泡、时钟走动、「看了第几次」的计数、朋友圈点赞、火苗；「事情 / 反应 / 需要」三层图逐层画出来；「换个人、换份工作」时上面两层换掉而最底层不变。这些只是提示，你可以想更好的。
2. **手绘感**：线条要像被一笔一笔画出来的（描边动画），可以用 roughjs 或 SVG 路径描边；纸张质感；手写风格字体可以用（见下面的字体说明）。
3. **镜头**：像白板讲解那样在一张大画布上平移和缩放，或者用其他你认为更好的镜头语言。整体要有电影感和节奏，不能像翻 PPT。
4. **音画同步**：画面动作要在旁白说到那个词时发生，用 captions.json 的逐字时间来调度。
5. **视觉母题**：设计一个可以贯穿整季的母题，比如三层图、一个小人、一种颜色标记。说明它在后面的集数里怎么复用和生长。
6. 避免：模板感、贴纸式剪贴画、emoji、颜色太多、满屏文字的 PPT 页。
7. 全部由帧驱动、结果可复现（Remotion 规范：用 `useCurrentFrame`，不用 CSS 动画或 `Math.random`）。

## 技术约束（很重要，有另一个 agent 在同时做同样的事）

- 只在你自己的目录里工作：`video-engine/src/lab/<你的名字>/` 和 `video-engine/public/lab/<你的名字>/`。
- 用你自己的入口文件 `video-engine/src/lab/<你的名字>/index.ts`（里面 `registerRoot`），渲染命令在 `video-engine` 目录下执行：
  `npx remotion render src/lab/<你的名字>/index.ts <合成ID> "../2_第二版资料/视觉实验/lab01_<你的名字>.mp4"`
- **不要修改**：`src/Root.tsx`、`src/index.ts`、`src/lib/*`、`src/styles/*`、`package.json`、`remotion.config.ts`。**不要 npm install**，只用已经装好的依赖：remotion 4.0.530、@remotion/layout-utils、@remotion/noise、@remotion/media-utils、@remotion/captions、roughjs、react 19。可以 import `src/lib/` 里的工具，但不要改它们。
- 音频用 `Html5Audio`（从 `remotion` 导入），`staticFile('episodes/lab01/audio.mp3')`。
- 字体：现有的是 `public/fonts/NotoSansSC-VF.ttf` 和 `NotoSerifSC-VF.ttf`（OFL）。如果要手写体，只能用 OFL 授权的免费可商用字体，从官方来源下载到你自己的 public 目录：霞鹜文楷 LXGW WenKai（github.com/lxgw/LxgwWenKai 的 releases）或 Google Fonts 上的 Ma Shan Zheng、Zhi Mang Xing、Long Cang、Liu Jian Mao Cao。不要用系统里的微软雅黑、华文、黑体、楷体。
- 音效、纸张纹理这类素材，用 Python/numpy 自己合成（参考 `src/styles/sketch/make_paper.py`），或者纯代码生成。项目的 Python 在 `D:\desk\claudex\24\.venv\Scripts\python.exe`。
- 渲染可以先用 `--frames=0-299` 快速看局部，最后渲染全片。

## 自我检查（至少迭代两轮）

1. 渲染后用 ffmpeg 每秒抽一帧，拼成接触印样，逐张看：
   `ffmpeg -i lab01_<名字>.mp4 -vf "fps=1,scale=480:-1,tile=6x10" -frames:v 1 sheet.png`
2. 对照参考片拆解和上面的要求，给自己挑毛病：哪里像模板，哪里画面不讲内容，哪里拥挤、看不清，哪里音画不同步。
3. 改完重新渲染。
