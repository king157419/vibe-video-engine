# 《隐藏条款》EP01 完整口播稿 + 分镜 + 自查

---

## 第一部分：口播稿

## 开场：补一句｜0:00–0:50

你发出去一句话。

对方正在输入……
闪了三次。
没了。
十八分钟，没有新消息。

别想，直接补。
你脑子里第一句是什么？
//

补上了吧。

对面这个人是谁，
你心里也填好了。

补得这么快。
快到你没来得及想。

没来得及想的话，
只能是**早就写好的**。

这种一碰就弹出来的
**如果……就……**，
我叫它：隐藏条款。

**让你难受的，**
**常常不是事，**
**是你自动补上的那句话。**

## 四种句尾｜0:50–1:35

同一条消息，
常见的补法有四种。

A，是不是出什么事了？
//
B，我得再发一条，把话说软一点。
//
C，是不是我问得太烦了？
//
D，TA就是没把我当回事。
//

你是哪个？
评论区打个字母。
两个都有，也正常。

看最后几个字。
出事、必须、不行、不在乎。

四件事：
**防，关，评，等。**

## 来源和第五格｜1:35–2:00

把难受分成这几类，
思路来自丛非从的
《养育你内心的小孩》。
书里叫安全感、自由、
价值感、亲密。
叫法和例子，是我的整理。

其实还有第五格。
唯一一格没有句子的。
先空着。

## 证据一：算得慢，补得快｜2:00–2:40

我说它是早就写好的，
凭什么呢？

你算一下。
**37乘24。**
//

笔会停，会进位。
真在想，就是这个速度。

刚才补那句，
你停了吗？
没有。
它自己弹出来的。

## 证据二：换人，句尾没换｜2:40–3:20

第二个证据。
换一个人，
句尾变不变？

飞书方案发给领导，
显示已读。
两个小时没回。
你把方案又打开了两遍。

家族群发体检结果。
你妈只回了一个：嗯。

你盯着看了半分钟。
打电话过去，第一句是：
你是不是不高兴？
//

工作，家人，
句尾没换。

## 证据三：知道也停不下来｜3:20–4:05

第三个证据，最狠。

你明知道TA可能在开车。
手还是打了一个问号。
删了。
又打了一个。

所以那句想开点，
不管用。

不是它不对。
是它**来得太晚**。

等你想开的时候，
该补的都补完了，
该做的也做完了。

## 自证循环｜4:05–4:55

更麻烦的是，
它还会**自己找证据**。

TA就是不在乎。
于是你回了一句：
随便你。
TA不说话了。
看吧。

找我肯定没好事。
于是你两点才睡。
会上答非所问。
领导皱了一下眉。
看吧。

**让你难受的，**
**常常不是事，**
**是你自动补上的那句话。**

## 自测：五道题｜4:55–6:15

五个场景。
每个停两秒。
按你最近七天
真遇到的时候，
冒出来的第一句选。

第一题。
周日晚上十点十分。
你想起明早十点的例会，
你要讲五分钟。
//
A，讲砸就完了。
B，今晚得再过三遍。
C，我肯定讲不清。
D，反正也没人认真听。
//

第二题。
下午五点五十二。
同事丢来半张表格。
说：这个你熟，帮我收个尾？
//
A，不接他会记仇。
B，我不接就没人做了。
C，推掉显得我不行。
D，就是看我好说话。
//

第三题。
领导在三十个人的群里
夸了你一句：
这次做得不错。
//
A，下次做不到就惨了。
B，以后都得这个标准。
C，其实是运气，他是客气。
D，平时做那么多，
怎么现在才看到。
//

第四题。
朋友聚会的合照发在群里。
九个人。
你在最边上，只露半张脸。
//
A，他们是不是另有个群。
B，我得赶紧在群里说句话。
C，我拍照就是难看。
D，根本没人在意我在不在。
//

第五题。
你妈打电话。
先说了两分钟天气。
然后叹了口气：
没事。
//
A，家里是不是出事了。
B，我得马上转点钱过去。
C，是不是我又哪做得不够。
D，有事也不跟我说。
//

数一数，
哪个颜色最多。

那是你最近
最常用的一条条款。

**颜色是给一句话的，**
**不是给一个人的。**
明天可能就换了。
这不是诊断，是一个习惯。

## 工具：抓·追·加｜6:15–7:15

现在拿开头那条消息，
把工具完整走一遍。

第一件事，**抓**。
把它写下来。
不方便写，
就说进语音备忘录。

如果TA不回，
就是那件事没戏了。

第二件事，**追**。
问然后呢。
最多三次。

没戏，我就得从头再找。
//

然后呢？
//

又没办成，
说明我就是办不成事。
//

注意。
第一句听起来像红的。
追到底，是蓝的。

你刚才打的字母，
可能只是表层。

## 工具：加一行｜7:15–8:15

第三件事，**加**。
旧的别删。
在旁边加一行。

最可能：
TA在忙。
或者还没想好。

我可以明天中午前，
不追问。

或者发一句：

**不急，**
**你周五前给我个准信就行。**

旧的留着。
旁边多一行，就够了。

## 真警报｜8:15–8:55

但有时候，
它说对了。

那条来我办公室一下，
可能真是谈你们组要撤。

概率可能是真的。
**所以我完了**，
是条款加的。

答案出来之前，
你是翻了一晚上招聘软件，
还是写好了三行预案？
//

还有。
这招管的是一句话。

如果你已经连着两周
睡不着、吃不下。
这张卡不够用。
去找专业的人。
全国心理援助热线，12356。

## 回收｜8:55–9:40

开头那个名字，
你心里填的是谁？
//

TA后来回了什么，
我不知道。
你也不用知道。

**让你难受的，**
**常常不是事，**
**是你自动补上的那句话。**

它在答案出来之前，
已经跑完了。

今天晚上，
打开跟这个人的聊天框。
找一条你停下来
多看了两眼的消息。

写一行：
**如果____，就____。**
圈一个颜色。

以后正在输入又没了，
先写这一行。
再决定发不发第二条。

## 下期｜9:40–10:00

下期，
拆最常见的红色。

一封邮件写错一个字，
脑子为什么直接跳到完了？
//

书里还讲了安全感的完整拆法。
感兴趣，去读原书。

这个系列叫隐藏条款。
下期见。

### 三、这稿最弱的三个地方

**1. 自测题压得紧，观众容易跟不上。** 五道题、二十个选项在 80 秒里过完，虽然每个选项只念句尾、有停顿，但只要观众走神两道，后面的计数就没有意义。这是大纲固定结构，我尽量把选项控制在 4–6 字，但这一段的节奏仍是全片最脆的地方。发布前建议用手机试看一遍，卡住就删一道题或把题目减到四道。

**2. 证据三的「想开点」翻案，逻辑上读者可能只记住了「不管用」，没记住「为什么不管用」。** 大纲要求先错后对，但 40 秒太短，赛道演示能讲清楚「太晚」，讲不清楚「早也没用」。如果这一版反馈偏弱，下一版可把这段和第 4–5 分钟的自证循环对调，让「自己找证据」先铺垫，再翻「想开点」的案，因果更顺。

**3. 「第五格问号」只挂了一次，没有第二次呼应。** 大纲把它放在 1:35 挂出，但后面 6 分钟里再没提过，悬到结尾的画面上才再出现。作为一个全季悬念，它在本期的存在感偏弱。下期开头可以加一句「上期那个问号，我们这期动它一格」，弥补第一期的不足。
