## 0.2 各稿逐项理由

**稿 A（2075 字，底稿）**
- 讲清楚：结构最完整。「我给你三个证据」把三段证据串成一条论证。软件协议的比喻让「条款」一听就懂：点了同意，一个字没读，之后自动生效。只有它回答了「为什么是加，不是改」，并把工具接回自证圆圈（圈断一环），机制是闭合的。扣分点：「补得越快，越不是你当场想出来的」说满了，较真的观众会反驳「直觉也快」；「看句尾：出事、必须、不行、不在乎」和四条原话对不上字面，C 句里并没有「不行」两个字。
- 留存：自测第 2、4、5 题的选项只上屏不念，锁屏听的人会断线；7:20–8:30 连着三块都在讲结构（加的原理、断圈、核心图总装），中间没有让观众动手。

**稿 B（1989 字）**

## 定义：隐藏条款｜0:21–0:50

补得这么快，快到你没来得及想。
没来得及想的话，只能是早就写好的。

这种一碰就弹出来的「如果怎样，就会怎样」，
我管它叫：**隐藏条款**。
就像装软件时那一长串协议，
你点了同意，一个字没读。
它签得很早，之后每次都自动生效。

让你难受的，常常不是事，
是你**自动补上的那句话**。

## 四种补法：你是哪个字母｜0:50–1:33

同一条没回的消息，常见补法有四种。
A，是不是出什么事了？
B，我得再发一条，把话说软点。
C，是不是我又说错话了？
D，对方就是没把我当回事。

你是哪个？评论区打个字母。
[停2秒]
两个都有，也正常。

别看前半句，看它最后落在哪。
A 落在出事，是在防危险。
B 落在必须，是把别的路关了。
C 落在我不行，是在给自己打分。
D 落在不在乎，是在等人把你当回事。
四个字：**防，关，评，等**。

为什么要写？在脑子里它一闪就过，
写下来，就得一个字一个字来。

再追，对着它问：然后呢？
没戏，我就得从头再找。
然后呢？又没办成，
说明我就是办不成事。
追到四种句尾之一就停，最多三次。
别停在「我会很烦」这种话上，
要追到一件具体的后果。

## 发现：红变蓝｜7:42–7:59

注意看颜色。第一句「没戏了」，
听着像红的。中间「得从头找」，
是橙的。追到底，「办不成事」，
是**蓝的**。你开头打的那个字母，
可能只是**最上面一层**。
颜色要追到底，才算数。

## 工具：加｜7:59–8:58

最后是加。旧的那句不用划掉，
在它旁边，加一行。
一行分两半：最可能是什么，
我可以怎么做，至少两种。

填进去：最可能是对方在忙，
或者还没想好怎么答。
我可以明天中午前不追问。
或者发一句：「不急，
你**周五前**给我个准信就行。」
这一句，把干等变成了截止时间。

为什么是加，不是改？
[停1秒]
改，就又在跟它比快，你比不过。
它管的是你下一步的手，
旁边多一行，手就多一条路。
你没回「随便你」，
回的是「周五前给个准信」，
那个圈，**就断了一环**。

一件事，一个动作，一句话，
一个句尾，再加一行。
这就是这一季的地图，以后每期添一样。

## 我认为这稿最弱的三个地方

1. **自测还是全片最长的一段（约 2 分钟）。** 字母顺序固定、选项全念之后，听的人能跟上了，但五题形式完全一样，第四题附近节奏会塌。第三题的「被夸也会补」是段内唯一的钩子。实测如果这里掉得厉害，先砍第四题（合照）：朋友这个领域在正片其他地方没有别的入口，但损失最小，能省约 20 秒。
2. **证据一仍然是类比，不是证明。** 「补得快，所以不是现算的」只把结论降到了「至少不是这一刻算出来的」，较真的人还能说「那叫直觉」。好在证据二（换人不换尾）和证据三（知道了也停不下来）接着补。如果评论区集中质疑这一点，EP02 开头可以用一句话回应：直觉也是早就写好的东西，这正是我们说的「条款」。

# 四、录音提示（给念稿的人）

**整体**
- 语速 **210 字/分**，像跟一个朋友解释一件事，不用播音腔，不用情感电台腔。全稿不需要「走心」的语气，越平越可信。
- 重音放在**句尾**（中文听感的重心在句末）：「是你**自动补上的那句话**」「就是**来晚了**」「是**蓝的**」。
- 稿里的 `[停N秒]` 是留给观众的空白，**真人录音时照停**，用手机秒表数，不要靠感觉。停的时候别吸气出声，别说「嗯」。
- 行尾换行不等于停顿，只是字幕断行。停顿看标点：逗号短停，句号正常停，空行（段落）停半秒到 1 秒。

**分段要点**

| 段落 | 怎么念 |
|---|---|
| 开场 | 「没了。」之前留一个小空，「然后没了」要念得轻、快。「别想，直接补——」破折号拖半拍，然后问「你脑子里的第一句话是？」，**停 2 秒**，再用轻松的口气说「补上了吧」 |
| 定义 | 「只能是早就写好的」稍慢。「隐藏条款」四个字一字一顿。答案句**三次用同一个语调**：平、稳，不煽情，「常常」轻，「那句话」重 |
| 四种补法 | 念 A–D 四句时换成「脑子里的声音」：轻、快、有点自言自语。字母念英文字母音（诶、比、西、迪）。「防，关，评，等」四个字之间各停半拍 |
| 来源 | 书名清楚、正常速度念，不压低，不加快 |
| 证据一 | 「你可能会说」用替观众抬杠的口气。「三十七乘二十四」放慢、咬字清楚，**停 3 秒**。「答案是八百八十八」要轻，像顺口一提。「没停。」干脆 |
| 证据二 | 三个小场景各自一口气念完，场景之间空行停 1 秒。「嗯」字单独念，短、平。「还是它吧？」**停 1 秒**。「人换了，句尾没换」全段最重的一句，放慢 |
| 证据三 | 「删了，又打了一个」念快，带一点无奈。「这话没错，就是来晚了」前半句让步、后半句落地 |
| 自证圆圈 | 两个「看吧」用**同样平的语调**，不要讽刺。「两次的证据都是真的」停一下，再说「可都是那句话自己造出来的」 |
| 自测 | 题干正常速度，四个选项**加快、轻读**，字母念清楚，每个选项之间停一小拍。每题后**停 2 秒**。第三题开头「被夸了，你也会补一句」带一点意外的口气 |
| 抓 · 追 | 两个「然后呢？」要像真在问自己，问完停半拍再接答案。「办不成事」落重 |
| 红变蓝 | 「是橙的」「是蓝的」一步比一步重，「蓝的」最重 |
| 加 | 「不急，你周五前给我个准信就行」用真的在发消息的轻松口气。「为什么是加，不是改？」**停 1 秒**。「就断了一环」落下来 |
| 真警报 | 语气转正经，但不沉重。热线号码逐个数字念「一、二、三、五、六」，中间各停一小拍 |
| 回收 | 「你心里填的是谁？」**停 1 秒**。「我不知道，你也不用知道」平静，不要安慰的口气。结尾三句逐渐放慢，「发不发第二条」念完就停，不拖尾音 |
