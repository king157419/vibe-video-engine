## 1. 结论速览

1. **形式**：以真人声音加动态字幕为骨架，再叠一种固定、能认出来的画面。建议先渲染 4 个 demo 让你挑：**① 暗夜电台·声波金句**、**② 治愈插画·缓推**、**③ 纸感知识卡片**、**④ 手绘框架·边画边讲**。“手+实体书”需要你自己拍素材，放到后面再做。
2. **渲染**：默认用本机已有的 **ffmpeg 8.1.2 + libass（ASS 字幕）+ h264_nvenc**，Python 做编排，不需要引入新的运行时。只有 ④ 这类描线动画要用 **HyperFrames**（Apache-2.0，锁定版本），备选是 **Remotion**（个人免费）。
3. **字幕时间轴**：文案是我们自己写的，所以流程是：**Qwen3-ASR 转写 → 和原稿做 diff，找出口误和重录 → Qwen3-ForcedAligner-0.6B 把最终文本强制对齐到音频**，得到逐字时间戳。厂商自测的中文平均误差是 33.1 ms，FunASR 的对齐器是 161.1 ms。兜底方案是 FunASR 的 paraformer-zh 加 fa-zh。Whisper 系不适合做中文主力。
4. **Skill 现状**：现在没有哪个 skill 能开箱即用地做好“中文口播 + 动态中文字幕 + 9:16”。能复用的是底层能力（渲染器、对齐模型）和几套剪辑规则（成峰「剪口播」、video-use）。编排要自己写，所有产物都以**我们自己的 JSON 为唯一真相源**。
5. **导出规格**：1080×1920，30fps 恒定帧率，H.264 High，yuv420p，约 8–12 Mbps，AAC 48 kHz。响度建议 **-14 LUFS / 真峰值 -1.5 dBTP**。抖音**没有公开的官方响度标准**。
6. **安全区（经验值，需要真机核对）**：关键内容放在 **x 80–880、y 240–1480** 以内。字幕块放在 **y 1280–1470**。右侧留 ≥200 px 给按钮列，底部留 ≥440 px。
7. **时长和语速**：用来拉新的单条做 **60–90 秒**，语速 **190–230 字/分**，也就是每条约 **220–320 字**。前 3 秒必须抛出钩子，0.3 秒内开口。
8. **版权是最大的风险**：照着原文朗读，在法律上等于复制；按章节复述全书，构成实质性替代。正确做法是**一期只讲一个观点，85% 以上是自己的话，直接引用不超过 2–3 句，并注明作者和书名**。最稳妥的是拿到授权，但要先确认对方确实有权授权（见 6.1）。
9. **AI 标识**：用了 AI 插画、TTS 或声音克隆，都**必须主动声明**。2026 年 5 月起，抖音发布时必须从 6 个必选标签里选一个，应标未标的内容进不了推荐池。烧进画面的字幕**只用 OFL 字体**（Noto Sans/Serif SC）。
10. **心理内容边界**：定位是“读书分享，不是心理咨询”。不诊断，不说“治疗”“治愈”，不卖课，不做一对一咨询。涉及自伤自杀话题时附上 **12356**，同时写 110/120。

## 2. 推荐技术栈（针对本机：Win11 + RTX 4070 Laptop 8GB + Node 22.18 + ffmpeg 8.1.2 full）

### 2.1 流水线总览

```
录音 WAV（48 kHz / 24 bit / 单声道）
 ├─①录音清理  ffmpeg: highpass=80 → afftdn(轻度) → loudnorm 两遍(I=-14, TP=-1.5, linear)
 ├─②转写/对齐 Qwen3-ASR-1.7B 转写 → 与原稿 diff（口误/重录/临场改词）→ 最终文本
 │             Qwen3-ForcedAligner-0.6B（最终文本 ↔ 音频，单段 ≤5 分钟）→ 逐字时间戳 JSON
 │             切点：重录句只留最后一遍；长停顿压短；切点吸附到字边界 + 30 ms 淡入淡出
 ├─③字幕      按原稿标点分句 → jieba 防止拆词 → 每行 ≤10 字、≤2 行 → 关键词高亮
 │             → 生成 ASS（\kf 逐字、\fad、\t）/ SRT / HyperFrames 转写 JSON（同一份数据）
 ├─④渲染      A 默认：ffmpeg filter_complex（背景/插画 zoompan/showwaves）+ subtitles=*.ass → h264_nvenc
 │             B 动效档：HyperFrames（HTML/SVG+GSAP，锁版本）；备选 Remotion 4.0.x
 └─⑤导出      MP4 1080×1920/30fps + 封面 PNG（=第一帧）+（可选）剪映 10.8 草稿，单向交接
```

### 2.5 备选路线（从上往下依次降级）

1. 如果 qwen-asr 装不上或者有冲突，改用 **FunASR paraformer-zh 加 fa-zh**。精度大约只有 Qwen 的五分之一，但做字幕够用，项目维护也更活跃。
2. 如果 HyperFrames 在 Windows 上不稳定，改用 **Remotion**。如果连 Remotion 也不想引入，④ 就退化成 ASS 的 `\p` 矢量绘图加 `\clip` 擦除动画，或者用 Python/ImageMagick 预先渲染 PNG 序列，再叠到画面上。
3. 如果全自动做不下去，就输出 **pyJianYingDraft 草稿**，让你在剪映 10.8 里微调后手动导出。剪映自己的“识别字幕”没法通过代码调用。

### 2.6 不推荐（附原因）

- **faster-whisper、WhisperX 不做中文主力**：中文时间戳精度一般，常常输出繁体。faster-whisper 的 pip 安装方式 README 只写了 Linux，Windows 官方路线是 Purfview 的打包库。
- **MoviePy** 不做主渲染器：比直接调 ffmpeg 慢，2.2.1 发布已经停了 16 个月。
- 已停更或已归档的：**stable-ts**（已归档）、**aeneas**（AGPL，最后一版 2017 年）、**AutoCut**、**Motion Canvas**（发布停滞）、**Revideo**（中间停了 17 个月）。

## 3. 可用的现成 skill 和开源项目

> 基本判断：网上视频类 skill 很多，但**都以英文为中心**。我们的结构性优势是**原稿已知**，所以字幕文本直接用原稿，ASR 只用来拿时间轴。目前只有 HyperFrames（能导入外部时间轴）和成峰「剪口播」（有“对照原稿校对”这一步）照顾到了这个场景。Anthropic 官方的 [anthropics/skills](https://github.com/anthropics/skills) 里**没有视频类 skill**。

### 3.2 炒作多于实用，不建议用

- **ffmpeg 类纯 prompt skill**（n0an、ychoi-kr、bryanwhl、JosiahSiegel 等）：7–57 星，安装量 151–680，内容就是 ffmpeg 速查。我们直接写 ASS 和 filter_complex 就行，**它们带来的增量很小**。
- **ffmpeg MCP**（kinocut、video-audio-mcp 等）：Claude Code 本来就能直接执行命令，包一层没有意义。video-audio-mcp 已经 16 个月没更新。
- **剪映/CapCut MCP**：capcut-mcp **已归档**，jianying-mcp 13 个月没更新。capcut-mate、VectCutAPI 主要面向 Coze、n8n 和云渲染。
- **[jianying-editor-skill](https://github.com/luoluoluo22/jianying-editor-skill)**：它的一键安装是 `irm is.gd/rpb65M | iex`，就是把短链接的内容直接交给 PowerShell 执行，**绝对不要用**。许可证是 NOASSERTION（非标准），自动导出需要剪映 5.9 这类旧版本。
- **anything2explainer**：PolyForm 非商用许可，只支持横屏。**digitalsamba video-toolkit**：依赖 Modal、ElevenLabs 等云服务。**nexu-io/html-video**：只是在 HyperFrames 外面又包了一层。
- **[VEED OpenEdit](https://github.com/veedstudio/open-edit)**（Apache-2.0，2026-07 创建）：支持 Windows，用 headless Chrome 逐帧渲染，可以用本地 WhisperX。文档没提中文和 9:16，太新，**先观察**。安装命令是 `npx skills add veedstudio/open-edit --skill open-edit`。
- **skills.sh 的安装量有水分**：HyperFrames 非交互安装时会一次装上全部 21 个 skill，所以“约 28 万安装”这种数字不能当作真实使用量。

### 3.3 安全规矩

第三方 skill 一律**先读 SKILL.md 和脚本再装**，按需用 `--skill <名字>` 装进项目的 `.claude/skills/`。不用 `irm|iex`、`curl|sh` 这类短链接一键安装。HyperFrames 和 Remotion 在 package.json 里要锁精确版本。

## 4. 视频形式候选

所有形式**共用一套包装**，这样账号才有辨识度。不露脸账号的四个记忆点是声音、开场句、构图、字幕样式，至少固定其中两样（[海螺社](https://www.hailuoshe.com/blog/no-face-short-video-formats)）。

| 共用元素 | 规格（1080×1920，30 fps） |
|---|---|
| 钩子大字（0–3 s，也就是封面帧） | Noto Serif SC Bold，96 px，每行 ≤8 字，最多 2 行，放在 y 300–700。人声在 0.3 s 内开口，不说“大家好我是” |
| 系列标识 | 左上角 x=80、y≈250：“养育内心的小孩 · 安全感 03”，Noto Serif SC 38 px，不透明度 75%。**账号名和标识里不要出现“丛非从”** |
| 正文字幕 | Noto Sans SC Bold，68 px，每行 ≤10 字（居中于 x=540，宽度 ≤680），最多 2 行，字幕块放在 y 1280–1470。深色背景用白字 #FFFFFF 加 6 px 描边 #141414；浅色背景用墨色字 #2B2B2B，不加描边 |
| 品牌高亮色 | 暖琥珀色：深色背景用 **#F5B942**，浅色背景用 **#C9771A**。每句 1–3 个关键词，高亮部分 ≤40%。**不用弹跳或抖动特效**（知识类内容忌讳综艺效果） |
| 片尾 2 s | “读书分享，非心理咨询 ·《养育你内心的小孩》丛非从 著”，Noto Sans SC 40 px |
| AI 角标（只在用了 AI 画面时加） | 开头显示“画面由AI生成”，文字高 ≥54 px（短边的 5%），持续 ≥2 s。这个参数来自对 GB 45438-2025 的二手解读，**要以标准原文为准** |

### 4.1 候选一览

**★① 暗夜电台·声波金句（demo 1）**
- **画面**：深色竖向渐变 #0E1116 → #1B2130，叠一层胶片颗粒（`noise=alls=6:allf=t`）和暗角。画面中部有一条细声波（showwaves cline，800×160，#E8D8B0，不透明度 55%，y≈880）。字幕逐句淡入（`\fad(150,120)`），关键词用琥珀色。说到金句时，屏幕中上方（y 500–760）出现 Noto Serif SC 72 px 的金句卡，停 3–4 s。加颗粒是为了防止深色渐变经平台压缩后出现色带，这是经验做法，**没有找到出处**。
- **参考类型**：深夜情感电台、朗读号，例如“泱泱朗诵·深夜情感电台”（[示例](https://www.douyin.com/video/7580369135202042214)），以及光音、山峰治愈电台一类（[知乎](https://zhuanlan.zhihu.com/p/669668487)）。
- **成本**：极低。**批量自动化**：高，纯 ffmpeg 就能做。
- **优点**：声音是绝对主角，陪伴感强，适合夜间场景和“听抖音”后台播放。
- **缺点**：画面信息量低，前 2 秒容易被划走；同质化严重。抖音开放平台的一份规范把“全程黑屏/白屏等无意义内容”“单图+大量文字”列为低质。不过这份规范管的是**短视频挂载小程序的达人**，不是普通视频的推荐规则，只能算旁证（[规范](https://developer.open-douyin.com/docs/resource/zh-CN/mini-app/operation/platform-capabilities/video/video-creator-promote-mount-mgmt-spec)）。另外要和“哄睡”这类有软色情争议的赛道划清界限。
- **为什么做 demo**：成本最低，最能凸显“声音好听”，可以作为基准线来对比其他形式。

**★② 治愈插画·缓推（demo 2）**
- **画面**：每个意群（8–12 s）配一张 Codex image_gen 生成的插画。风格固定为暖色水彩或蜡笔，主色是奶油 #F6EFE3、蜜桃 #F2B8A0、鼠尾草绿 #A8C3A0。画面是小孩与大人的剪影或背影，**不画写实人脸，不画书页文字**。每张图用 zoompan 从 1.00 缓推到 1.06，图与图之间 0.6 s 交叉淡化（xfade）。字幕加 55% 黑色半透明圆角底块，因为插画背景的明暗不一。标题用 Noto Serif SC，如果想要楷体的感觉，可以装霞鹜文楷。Codex 生成的图按 CLAUDE.md 的记录是 1254×1254 的方图，要么让它直接出竖图，要么把方图放在画面中上部，再用同一张图模糊后铺满背景。
- **参考类型**：AI 读书号流水线，比如侧脸人物配山水、毛笔大字（[X 帖](https://x.com/laowangbabababa/article/2100939767743742025)）；Coze 上的“治愈语录”工作流。
- **成本**：低，每期 4–8 张图。**批量自动化**：高。
- **优点**：氛围最强，和“治愈”主题最搭，画面有变化。
- **缺点**：**必须做 AI 标识**；很容易“千号一面”。网信办 2026-04-30 启动的“清朗·整治AI应用乱象”专项行动，点名打击批量生成的“数字泔水”（[网信办](https://www.cac.gov.cn/2026-04/30/c_1779289298718765.htm)）。开头千万不要用慢热的空镜。
- **为什么做 demo**：视觉上限最高。同时可以借这个 demo 测一下：你能不能接受 AI 标识，以及自定义画风能不能拉开和其他账号的差距。

**★③ 纸感知识卡片·动态排版（demo 3）**
- **画面**：米色纸张底 #F4EEE3，叠一层细纸纹噪点，文字用墨色 #2B2B2B。每个意群是一张卡片：先出关键词大字（Noto Serif SC Bold 120 px），从下方 20 px 处淡入，持续 200 ms，不弹跳；然后 2–3 条要点逐条堆叠出现（Noto Sans SC 56 px）；高亮用马克笔底块（#F5B942，不透明度 35%）。底部字幕用 `\kf` 逐字从灰色 #9A948A 填成墨色。换卡时向左滑出，250 ms。
- **参考类型**：不露脸的知识口播号，剪映口播字幕模板一类。
- **成本**：低。**批量自动化**：高，用 ASS 的 `\move`、`\fad`、`\t`、`\kf` 就能全部做完。
- **优点**：静音状态下也能看懂，信息密度高，收藏率导向；不用 AI 画面，所以**不需要 AI 标识**。
- **缺点**：容易有 PPT 感，看多了会疲劳；卡片模板每期都要换些变化，避免被判“重复画风”。
- **为什么做 demo**：合规成本最低（没有 AI 素材），又最能体现“解读”而不是“朗读”，符合版权策略。

**★④ 手绘框架·边画边讲（demo 4）**
- **画面**：白板或纸张底 #FAFAF7，线条 #333，粗 4 px，要有手绘的抖动感。中心是“内在小孩”的简笔画，周围环绕五个圆：安全感、自由感、价值感、意义感、亲密感。讲到哪个概念，就用 SVG stroke-dashoffset 描出那个圆，并用 #F5B942（不透明度 40%）填色，时间和字级时间戳同步。每期只揭示和本期相关的部分，其余保持浅灰 #CFCFCF。标签用 Noto Serif SC（或霞鹜文楷），字幕放底部。
- **参考类型**：“混子哥边画边讲”，白板配画外音，入驻半年涨粉 1400 万（[维科号](https://mp.ofweek.com/Internet/a556714709587)）。注意有幸存者偏差：他就是“半小时漫画”的作者陈磊，背后有团队和十年的积累。另外，抖音官方把“边画边讲”点名为 2025 年人文知识的两大创作趋势之一（[中国日报网](https://cn.chinadaily.com.cn/a/202512/30/WS69538831a310942cc4999637.html)）。
- **成本**：中等，每期要设计一张框架图，可以由 Claude 生成 SVG。**批量自动化**：中等，用 HyperFrames（HTML/SVG 加 GSAP），备选 Remotion。
- **优点**：原创感和知识感最强，也最贴合这本书的“五感”框架；是官方点名的趋势；框架图本身就是对全书的**再创作**，不算复述。
- **缺点**：要引入 Node 渲染器；每期都要画新图，是产能瓶颈。
- **为什么做 demo**：差异化最强，而且可以借它验证动效档的技术栈能不能在本机跑通。

**⑤ 手 + 实体书 + 画外音（半出镜，暂不做 demo）**
- **画面**：俯拍桌面，镜头里只有手、一杯茶和实体书，翻页、划线、合上书，配画外音和字幕。**不拍能看清文字的整页**。
- **参考**：都靓一类的荐书号（[新华网](http://www.xinhuanet.com/fortune/20240407/099e300632f9497aa947b03ad581e57a/c.html)）。
- **成本**：中等，需要你自己拍素材。**自动化**：低到中，素材拍好以后可以套用同一个字幕引擎。
- **优点**：信任感和带货转化都强，符合“活人感”风向。**缺点**：书页入镜有版权风险；需要布光和摆拍。
- **为什么暂不做**：没有素材就没法渲染。等你从前 4 个里选定主风格后，可以把它作为“带货期”的专用形式。

**⑥ 真人出镜或视频播客长谈（后期扩展，暂不做 demo）**
- 露脸口播，或者 20–40 分钟的长谈播客。“抖音视频播客”是 2026 年的官方重点方向，“听抖音”也有利于长时长内容。成本中到高，自动化低。适合在账号有了基础之后再做。

## 5. 抖音技术规格与安全区

### 5.1 导出参数

| 项目 | 建议值 | 依据 |
|---|---|---|
| 分辨率和帧率 | 1080×1920，30 fps 恒定帧率 | 开放平台上传接口推荐 720p 及以上，mp4 或 webm，单个文件 ≤4 GB，接口上传时长 ≤15 分钟（[开放平台](https://open.douyin.com/platform/resource/docs/ability/content-management/douyin-publish-solution)）。客户端和网页端的时长上限以你账号上传页的提示为准 |
| 视频编码 | H.264 High，yuv420p，NVENC `-cq 19`（或 x264 CRF 18–20），约 8–12 Mbps，加 `+faststart` | “码率超过 6000 kbps 会被二次压缩”是 2020 年的传言，原文就写着“据说”（[B 站](https://www.bilibili.com/read/cv8004226)），**未证实** |
| 音频编码 | AAC-LC，48 kHz，192–256 kbps | — |
| 响度 | 综合响度 **-14 LUFS**，真峰值 **-1.5 dBTP**。背景音乐比人声低 18–25 dB | 抖音**没有官方标准**（[知乎提问](https://www.zhihu.com/question/500002600)）。有官方文档的参照：Spotify 回放归一化到 -14 LUFS，建议真峰值低于 -1 dBTP（[Spotify](https://support.spotify.com/us/artists/article/loudness-normalization/)）；Apple Podcasts 是 -16 LKFS ±1（[Apple](https://podcasters.apple.com/support/893-audio-requirements)）。YouTube 的 -14 LUFS 是社区实测，不是官方数字。火山引擎音频转码 API 默认 -12 LUFS，那只是云 API 在 2Pass 模式下的默认参数，**不是抖音的播放标准**。社区有人说“剪映一键均衡到 -23 LUFS”，**未证实，值得实测** |
| 水印 | 不要带其他平台的水印或 logo | 开放平台提示这类视频可能被降权或下架 |

### 5.2 安全区（1080×1920）

```
y=0     ┌──────────────────────────────┐
        │ 顶部避让 ≥160 px（同时发视频号的话 ≥230 px）│  状态栏、推荐/关注标签、搜索
y=240   ├── 关键内容上沿 ──────────────┤
        │ 系列标识 y≈250（x=80 起）          │
        │ 钩子大字 y 300–700                │
        │ 主画面、插画、图解                 │  右侧按钮列约在 y 700–1700：
        │                                  │  x>880 的区域不放关键内容
        │ 字幕块 y 1280–1470（2 行 × 68 px） │
y=1480  ├── 关键内容下沿 ──────────────┤
        │ 底部避让 ≥440 px                  │  @昵称、标题文案、话题、音乐、合集条、进度条
y=1920  └──────────────────────────────┘
左边距 ≥80 px；关键内容 x ≤880（右侧留 ≥200 px）
```

- **依据都是经验值，来源可信度偏低**。各第三方给的数值差异很大：顶部 140–220 px，底部 300–400 px，右侧 120–194 px。DataBrush 那篇（[链接](https://www.databrush.com/article.php?id=595)）自己标注是“模拟整理”，疑似 AI 生成的填充文章，**不能当证据**。CreaMate 是营销博客。视频号的 46/154/96 px（按 720×1280 给出）来自腾讯广告代理商的转载，而且只适用于广告素材（[链接](https://www.teng-ad.com/jd/3731.html)）。所以上面的框是综合各家后取的保守值。
- **核对方法**：用剪映专业版 **≥7.8**，草稿比例设为 9:16，打开“安全区”和“抖音预览”叠加层（[搜狐](https://www.sohu.com/a/881817861_120142897)）；再结合真机发一条私密视频截图。我们的流水线也会额外渲染一张安全区叠加图，用来检查。
- **封面**：抖音主页网格按约 3:4 居中裁切（[cardcrafter](https://www.cardcrafter.cn/guides/douyin-cover-sizes)），所以封面标题放在 **y 300–1300**，并把封面同时设为视频第一帧。封面结构：系列名 + “安全感 03” + 一句 2–6 字的钩子。模板可以固定，但每期的标题和主视觉要换，避免被判“重复画风”。

### 5.3 字幕规范

- 字号 64–72 px，每行 8–12 字，最多 2 行。原来来源里“12–16 字、65–85 px”的建议有问题：16 字 × 85 px = 1360 px，比画面还宽（[pixmojo](https://pixmojo.cn/blog/video-subtitle-text-guide) 的数值已经按本机画布修正过）。
- 描边宽度约为字号的 8–12%，或者用 55–70% 不透明度的黑色底块。正文用无衬线字体，衬线体和楷体只用在标题和金句上。
- 每个字显示 0.2–0.25 s，每屏至少 1.2 s，说完后多停 0.3 s。
- 考虑到有人用“听抖音”只听不看，**文案里不要说“大家看屏幕上……”这类话**。

### 5.4 语速与时长

- **语速**：190–230 字/分，句与句之间停 0.3–0.6 s。参照：日常说话 200–260 字/分（[灵感提词器](https://aiteleprompterapp.com/zh/use-cases/social-video-recording)），快节奏口播约 330 字/分。注意来源之间有矛盾：翔宇说“200–400 字对应 40–80 秒”，折算下来是 300 字/分，比治愈调性快很多。按 230 字/分算，200–400 字其实是 52–104 秒。
- **目标时长**：
  - 拉新单条 **60–90 s**，约 **220–320 字**。
  - 主题长版 3–8 分钟，**按主题重组，不按章节浓缩**，原因见 §6.1。
  - “一口气读完”式的长版有流量红利：30 分钟以上的中长视频数量同比增长 207%（[北京日报](https://xinwen.bjd.com.cn/content/s6960ca6ce4b0687a288f81a8.html)）。但在没有授权的情况下，这种形式**版权风险最高，不建议做**。
- **完播参考**（第三方经验值，不是官方数据）：2 秒跳出率 <35%，5 秒完播率 >35%，整体完播率 >10%；1 分钟以上的视频，完播率 10–15% 就算优秀（[极致了](https://www.jzl.com/news/douyin-data-70)）。
- **钩子公式**：痛点代入 / 反常识 / 悬念提问 / 结果前置 / 场景切片。**钩子抛出的问题，正文里必须给出答案**，否则属于诱导互动。抖音规则中心也禁止标题党。

### 5.5 发布节奏和合集（经验值）

- 每周 3 条 60–90 s 的短视频，每两周 1 条主题长版，固定在 20:30–22:30 发布。这个时段的依据来自第三方，可信度一般。
- 前 20 条的开场句和构图先定死，之后再看数据迭代。
- 合集在网页端创作者中心“合集管理”里建。App 端能不能建，各方说法矛盾，**以你账号实际看到的入口为准**。
- 合集名称和简介能被搜索到，要写进关键词。

## 6. 规则与风险清单

### 6.1 版权（最重要）

**法律框架**：《著作权法》第 24 条第 1 款第 2 项允许“为介绍、评论某一作品或者说明某一问题，在作品中适当引用已经发表的作品”。前提有三个：**注明作者和作品名称**；**不影响作品的正常使用**；**不得不合理地损害权利人的合法权益**。法律没有规定字数上限，看的是引用是否在必要范围内。北京高院审理指南 7.11 条列了四个考量因素：是否已发表、引用目的、引用比例、是否影响原作的正常使用。“安全感、自由感……”这类概念框架属于思想，不受保护；受保护的是作者的**具体文字、比喻、咨询案例叙述，以及章节的选择和编排**。

| 判例 | 要点 | 对我们的含义 |

**Do**
- 每期都要口播说明“丛非从在《养育你内心的小孩》里说……”，字幕也标出书名和作者。这是第 24 条的法定要求。
- **一期只讲一个观点**，把书里的观点翻译成日常问题（比如“为什么我总讨好别人”），然后用你自己的理解、经历、化名或虚构的例子，再加上反思性的问题去展开。
- 直接引用**每期不超过 2–3 句，合计约 100–150 字**，占口播比例在 10–15% 以内（经验值）。每句引用后面紧跟你自己的评论。
- 整个系列**按主题重组**，不要按章节顺序把全书完整覆盖一遍。每期结尾引导观众去读原书，可以挂正版书链接。
- 用自己合法购买的纸书或正版电子书当参考文本。
- 最稳妥的做法是**拿到书面授权或达成分销合作**。果麦 2025 年报把这本书和《5%的改变》等一起列为心理自助赛道“表现不俗”的书目，也披露了在做外部达人带货（[年报](https://money.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?stockid=301052&id=12041213)）。但要注意**授权链条**：果麦可能只有出版权或电子书权利，不一定能授权视频或音频形式的改编和信息网络传播，必要时要找作者本人授权。

**Don't**
- 不要朗读原文，哪怕只读一节。
- 不要做“一集讲完第 X 章”式的逐章浓缩。标题里不要出现“X 分钟读完”“全书精华”。
- 不要复述书里的咨询案例和故事。这些是作者独创性最强的表达，也涉及来访者隐私。
- 不要拍能看清文字的书页，不要做“金句截图”合集，不要用盗版 PDF 截图。
- 不要用作者的照片、视频、声音。账号名、头像、简介不能暗示“丛非从官方”或“已获授权”。抖音社区自律公约禁止假冒他人的姓名和身份。
- **用户最初的设想（“把书里不同部分做成不同期”）需要调整**：把 36 篇逐篇拆成 36–50 期，等于用系列视频把全书讲一遍，替代效应很明显。建议改成“36 个日常问题，每期借书里的一个观点来回答”。

### 6.2 原创判定与同质化

- 抖音**没有公开针对读书内容的原创判定细则**。第三方文章里的“四层识别”一类说法都不是官方口径。据报道，“暗水印”能力 2026 年 3 月上线，目前只用于广告素材（[虎嗅](https://www.huxiu.com/article/4839245.html)）。
- 平台在往原创方向倾斜：2025 年创作者大会宣布为优质内容单独建推荐池，并加大打击非原创内容（[新华网](http://www.xinhuanet.com/tech/20250924/187cfb6418bd4e8c94111c273cc2bbaf/c.html)）；2026-09-20 的大会又宣布升级原创分发机制（[北京日报](https://xinwen.bjd.com.cn/content/s6aaf530fe4b039a8e2f14f38.html)）。
- 自动化流水线真正的风险是**批量同质化**。2026 年春节“清朗”专项点名了 AI 批量生成的雷同低质内容和 AI“专家科普”（[新华网](https://www.news.cn/legal/20260212/c7ad9636adb44ce7a89f41d6f4a15376/c.html)）；“清朗·整治AI应用乱象”专项行动从 2026-04-30 开始，为期 4 个月。
- 对策：用真人原声，文案自己写，每期的画面、主视觉、卡片布局都要有变化，不要一套模板换词量产。
- 关于 AI 的数据：2025 年 11 月比 3 月，抖音 AI 投稿量增长 185%。这组数据出自抖音自己的《2025 抖音AIGC创作年度报告》，平台其实在**扶持优质 AI 内容**（[央视网](https://v.cctv.com/2026/03/24/ARTIKONDgDNj9edAitnAi5OD260324.shtml)），所以“真人声音一定有流量优势”只是推论。真正的约束来自监管和同质化治理。

### 6.3 AIGC 标识

- **《人工智能生成合成内容标识办法》**2025-09-01 起施行，同日施行的还有强制性国标 **GB 45438-2025**（[网信办](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)，[国标](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=F32EA2A561F1886CD8D606513512D547)）。显式标识（第四条）和隐式标识（第五条）的义务主体是**服务提供者**。**个人发布者的义务在第十条**：主动声明，并使用平台提供的标识功能，不得删除、篡改、隐匿标识。《深度合成管理规定》第 17 条的义务主体同样是服务提供者，用户对应的是第 18 条（[gov.cn](https://www.gov.cn/zhengce/zhengceku/2022-12/12/content_5731431.htm)）。第 14 条要求编辑人声要取得被编辑人的单独同意，这进一步支持“只克隆本人声音”。
- **执法已经落地**：2026-04-28，剪映、猫箱、即梦 AI 因为没有有效落实标识规定，被约谈、责令改正并警告（[网信办](https://www.cac.gov.cn/2026-04/28/c_1779119736411711.htm)）。
- **抖音的操作**（2025-09 的说法，一年后界面可能已经变了，**要实际核对**）：发布页 → 高级设置 → 发文助手自主声明 → 内容由 AI 生成。没有主动声明的，平台可能会打上“疑似使用了AI生成技术”的标签；读到文件元数据里的隐式标识时，会打上“作品含AI生成内容”（[证券时报](https://www.stcn.com/article/detail/3315850.html)）。
- **2026 年 5 月起的必选标签**：平台必须提供 6 个标签：含有虚构演绎内容 / 含有AI生成内容 / 含有营销信息 / 内容为转载 / 内容为个人观点 / 无需标注。发布时必须选一个，存量视频会被回溯补标（[网信办](https://www.cac.gov.cn/2026-05/12/c_1780328273038196.htm)）。能不能多选，以发布页实际选项为准。2025 年 7 月的“清朗”专项已经明确：**应标未标的内容不得进入推荐池**（[gov.cn](https://www.gov.cn/zhengce/zhengceku/202507/content_7034303.htm)）。

| 做法 | 是否要 AI 标识 | 建议标签 |
|---|---|---|
| 真人原声 + 非 AI 画面（③ 卡片），文案由 AI 起草、本人修改 | 主流解读认为一般不需要，但属于**灰色地带** | 内容为个人观点 |
| 真人原声 + **AI 插画**（②） | **需要** | 含有AI生成内容，再加片头角标；**不要删除图片元数据** |
| TTS 或 GPT-SoVITS 克隆**本人**声音补的句子 | **需要**（合成人声） | 含有AI生成内容 |
| 克隆丛非从或其他名人的声音或形象 | **禁止**（殷某案判赔 25 万元，[链接](https://titanlaw.com/news/detail/2180)，另见李某某案） | — |
| 挂购物车 | — | 含有营销信息，再按《互联网广告管理办法》第 9 条显著标明“广告” |
| 用虚构案例做情景演绎 | — | 含有虚构演绎内容 |

### 6.4 心理内容的边界

- **《精神卫生法》第 23 条**：心理咨询人员不得从事心理治疗，也不得诊断或治疗精神障碍（[链接](https://xxgk.jccq.gov.cn/qzf/cqwtj/fdzdgknr/ylwsly/xzcflsx/202112/t20211201_1504995.shtml)）。心理咨询师 2017 年已经退出国家职业资格目录。
- **国家卫健委 2025-11-06 的健康提示**：以心理健康科普的名义违规导医导诊、带货卖课，涉嫌违法；并批评简单归因、制造焦虑的做法（[北京日报](https://xinwen.bjd.com.cn/content/s690c807de4b02424b0c29b57.html)）。
- **资质与人设**：网信办要求医疗卫生等领域的自媒体提供资质认证（[网信办 2023](https://www.cac.gov.cn/2023-07/10/c_1690638496047430.htm)）。抖音 2024-07 治理虚假人设，点名了“情感心理咨询师”“人生导师”这类无法验证的头衔（[澎湃](https://www.thepaper.cn/newsDetail_forward_28163268)）。2025 年“清朗”专项点名了**杜撰或篡改真实案例细节**的做法。
- **落到本项目**：
  - 账号定位是“读书分享、个人成长”，简介写明“读书分享，非心理咨询”。
  - 不自称咨询师、疗愈师、导师。
  - 不用“治疗、治愈、诊断”这类词，不做“测测你是不是 XX 人格障碍”。
  - 不在评论区或私信做一对一咨询，不卖课。
  - 书里原生家庭的话题很多，**不要把问题都归咎于父母，不要渲染家庭对立**。
  - 书里的案例要说成“书中提到的一种情况”，**绝不能说成“我的来访者”**。
- **自伤自杀**：抖音禁止宣扬、美化自杀自残，讲相关经历时必须有充分的风险提示（[规则中心转载](https://www.sohu.com/a/877535904_121423427)）。碰到这类话题时：不描述方式方法，不浪漫化；片尾和置顶评论附上“全国统一心理援助热线 **12356**”（[新华网](https://www.news.cn/politics/20250508/b45e439c15bb4732858ad5c7640e9ba9/c.html)），同时写上 **110/120**，因为 12356 每天服务不少于 18 小时，**不保证 24 小时**。私信里遇到危机表达时，只引导对方拨打热线，不要自己做干预。

### 6.5 图书带货

- **门槛**：实名认证并年满 18 岁；个人号**有效粉丝**（不是粉丝总数）达到 200 可以直播带货，达到 500 可以短视频带货并开橱窗，达到 1000 可以图文带货；可以 0 元入驻，但之后要补缴保证金；连续 180 天没有成交会释放带货权限。这套门槛是 2025-04-17 生效的（[电商派](https://www.pai.com.cn/p/01jrcmkg2b8b5qwmjtbpt81312)）。“2026-02-10 修订”的说法**未证实**，**以 App 内显示为准**。
- **图书严管**：抖音电商 2026-04-07 发布违规图书专项治理公告，针对无资质售书、恶意错放类目、虚假宣传，对达人的处置包括关闭商品分享权限、冻结佣金（[腾讯新闻](https://view.inews.qq.com/a/20260410A03O8E00)）。**只推广有出版物经营许可的正规店铺的正版书**，最好是果麦官方渠道。
- **广告标识**：《互联网广告管理办法》第 9 条规定，以知识介绍、体验分享等形式推销商品并附购物链接的，要显著标明“广告”。第 8 条规定，介绍健康知识时，**同一页面不得附医疗、药品、保健食品的购物链接**（[gov.cn](https://www.gov.cn/zhengce/202305/content_6858084.htm)）。所以只挂书，别挂保健品或“疗愈”类商品。
- 不能用作者的影像或 AI 声音为带货背书（李某某案）。

### 6.6 素材授权（自动化流水线最容易踩的坑）

- **字体**：
  - 字幕和画面文字**只用 Noto Sans SC / Noto Serif SC**（SIL OFL，可以商用），或者自己装的霞鹜文楷（OFL）。
  - **不用**微软雅黑（版权属于方正，商用要授权，[21 经济](https://m.21jingji.com/article/20190306/herald/21380cbb7ace31c6cc8fe4f50089ebed.html)）。
  - **不用**华文楷体、华文行楷、华文中宋：即使系统预装，用于自媒体也要另外购买授权（[华文](https://sinotype.vcg.com)）。
  - **不用** SimHei、SimKai：权属有争议，保守起见规避。
  - 本机虽然装了 STKaiti、STXingkai，**成片里也不要用**。
  - 方正黑体、书宋、仿宋、楷体、甲骨文这五款对“发布使用”是免费的（[方正](https://www.foundertype.com/index.php/About/powerbus.html)），可以作为楷体风格的合规选项。
- **配音**：正式发布用真人原声。edge-tts 只用来做内部 demo。
- **背景音乐**：用抖音曲库，或者确认可以商用的音乐。
