# 07 找热点的工具（2026-10-14 实测）

> 测法：每个能公开访问的地址，都用 WebFetch 真打了一次（失败的再打 1–2 次）。
> 不登录、不用 cookie、不改代理、没装任何东西。
> 「我们」= Claude 在这台电脑上的会话；「你」= 用户本人，在手机上看。
> 说明：这次调研中途，所有调研 agent 共用的 WebSearch 额度（200 次）用完了。所以后半段只靠 WebFetch 直接打开已知地址。凡是只能靠搜索才能确认的，都标了「（未核实）」。

---

## 一句话结论

我们能直接用的，只有「聚合站首页 + B 站公开接口」：**今日热榜 tophub.today 首页、rebang.today、B 站热门/热搜/联想词接口**，6–8 次调用就能看全抖音、微博、知乎、百度、快手、小红书、B 站的热榜。
抖音、微博、知乎、百度、巨量算数、小红书的**官网和接口，我们一律连不上**（WebFetch 报 Socket is closed）。
抖音里真正懂「什么题会火」的工具——**热点宝、创作灵感、巨量算数**——只能你在手机上看。
装一个 MCP（mcp-trends-hub）能让抖音热搜拿得更稳，但不是必须；要装得你点头。

小结：

- **WebFetch 连国内平台本站基本都断**（抖音、微博、知乎、百度、小红书、巨量算数全是 Socket is closed）。原因没核实，多半是这些站拒绝海外机器。
- **聚合站反而能用**。tophub 首页和 rebang.today 把这些平台的榜都转了一遍，我们读聚合站就够了。
- **B 站是唯一能直接读官方数据的平台**。

## 二、分类细节

### (a) 官方工具

| 小红书 | 生活方式、情绪类 | 直连不行，读 rebang 的「小红书」页 | 可选：小红书创作中心的灵感（未核实） |

B 站接口的两个坑（实测）：

1. **旧分区号的排行榜停更了**。`ranking/v2?rid=36`（知识区）返回的视频大多是 2025 年 3 月底到 4 月 2 日发布的（最早一条 2025-02-04），10-14 复查看到的 90 多条里没有 2026 年的。用全站榜（rid=0）或综合热门，不要用旧分区号。
2. **只用这几个不带登录的接口**。B 站的搜索接口要 cookie，会触发 412 风控，按规矩不碰（按规矩没测，未核实）。

tophub 的坑：有些榜早就不更新了。实测看到京东热销标着 2026-06-26，机器之心标着 2025-11-25，微信 24h 热文榜标着 2026-09-22（10-14、10-15 两次复查都一样）。
微信榜停在 9-22 是对的：榜里最新的一条是名古屋亚运会男篮决赛（韩国胜日本拿金牌），这场决赛在 2026-09-20 打（新浪 9-19 的赛程文章）；榜里没有任何 10 月的内容。百度榜里有国庆消费这类 10 月的词，没停更。
复查时还看到：Apple Music 标 2025-11-13，IMDb 标 2026-01-08，吾爱破解标 2026-03-09，咖啡日报标 2026-04-28，北大未名标 2026-05-08，优设网标 2026-06-02，厦门小鱼标 2026-09-24，雪球标「4 天前」。QQ 音乐 10-14 晚标「5 小时前」，10-15 上午标「15 小时前」，说明它一天才更新一次左右。找音乐类热点（比如「歌词放映」用的歌）时尤其要注意。**每个榜都要先看它旁边的时间**。

star = GitHub 上的收藏数，大致代表多少人在用。

mcp-trends-hub 的一个细节（读了它的源码）：

- 微博：直接请求 `weibo.com/ajax/side/hotSearch`，**不带 cookie**。
- 抖音：先向抖音的一个登录引导接口要一个**匿名** cookie（`passport_csrf_token`），再拿它去请求热搜接口。这个 cookie 不是你的账号，也不用登录。但严格说算「用了 cookie」。**算不算违反规矩，由你定。**

我们这个号做抖音，海外榜只在一种情况下有用：**国外先火、两三周后传到国内的东西**（比如今天抖音榜上的「火遍外网的 ChinaHaul 是什么」）。平时不用看。

会话里有 vidiq 的 YouTube 工具，但每次调用花你的额度，按规矩没用。

## 三、用这套工具看一眼今天（10-14）的榜

不是选题提案，只是演示「热点 → 有名字的大想法」怎么接。

| 榜上的词 | 在哪个榜、多热 | 能接的大想法 | 接得上吗 |
|---|---|---|---|
| 入职第一天因截图社死 | 微博 223 万（tophub）/ 190 万（rebang） | 聚光灯效应（Spotlight effect）：你以为所有人都在看你，其实没有。维基说这个词由 Gilovich、Medvec、Savitsky 提出；1999 年 Gilovich 和 Savitsky 的综述里已用这个词，三人做实验（穿尴尬 T 恤那个）的论文是 2000 年 | 能。开头 10 秒能在观众身上发生一次 |
| 今年双 11 告别算数题 | 百度 780.8 万（10-15 复查时这个数正好对应第 2 名，像是跟着名次走，见下注） | 心理账户（Mental accounting），Richard Thaler（相关论文 1980、1985 年） | 能，但双 11 题会很挤 |
| 今年冬天会更冷还是更暖 | 百度 752.2 万（10-15 复查时这个数对应第 5 名，同上） | 天气类（要另查具体概念） | 贴季节，和「萤火」的「贴季节和天气」一致 |

## 四、对我们有什么用

### 可借鉴

- 聚合站首页一页顶十个平台，比一个个平台去试省事得多。
- B 站「联想词」接口是个好东西：输入一个题，看大家实际怎么搜。可以用来**验证一个冷门题有没有人搜**，也可以从长词里挖标题（比如「梵高死了人们才开始欣赏他的作品」）。
- 热榜大多是新闻和八卦。我们要找的是**能挂上一个有名字的大想法**的那几条，不是第一名。

### 建议

**(1) 我每次找热点的最小工具组合（按顺序，约 6–8 次 WebFetch）**

| 顺序 | 调什么 | 拿什么 | 次数 |

| 5 | WebSearch（先 standard，太新再 extended） | 某个热点**为什么**火、哪天开始的 | 按需 |

**写进「萤火」skill 的建议**：把 SKILL.md 第 79–83 行「找热点」那段里的「用 WebSearch 搜公开热榜」换成上面这张表。这次只是建议，没改 skill。

**(2) 你在手机上自己看哪几个（每周 2–3 次，每次 5 分钟）**

**(3) 要不要装 MCP**

现在不装也能用：上面的 WebFetch 组合已经覆盖了抖音、微博、知乎、百度、小红书、B 站。
装 mcp-trends-hub 的好处有两个：抖音热搜能直接拿到热度值和事件时间；万一 tophub 和 rebang 哪天也 403 了，还有后路。
它跑在你电脑上，用你的国内网络，所以抖音、微博、知乎能连上（没实测，因为没装）。

**需要你同意才装。** 装的时候会从 npm（Node 的软件包仓库）下载 mcp-trends-hub 和它的依赖（axios、zod 等）。装完要开新会话才生效。
抖音那一项会向抖音要一个匿名 cookie（见上文 (d)），你先决定能不能接受。

装法一：在 `D:\desk\claudex\24` 里开终端，跑这一行（只对这个项目生效）：

```
claude mcp add --scope project trends-hub -e TRENDS_HUB_HIDDEN_FIELDS=cover -- cmd /c npx -y mcp-trends-hub@1.7.0
```

（核查时改过：原来写成 `-e ... trends-hub --`，名字紧跟在 `-e` 后面。官方文档说这样名字会被当成另一个 KEY=value 而报错，所以把名字挪到 `-e` 前面。本机 `claude mcp add --help` 的例子就是这个顺序：`claude mcp add my-server -e API_KEY=xxx -- npx my-mcp-server`；官方文档也有 `claude mcp add example --env API_KEY=your-key -- npx -y @example/mcp-server`。）

装法二：等价地，在 `D:\desk\claudex\24\.mcp.json` 里写：

```json
{
  "mcpServers": {
    "trends-hub": {
      "command": "cmd",
      "args": ["/c", "npx", "-y", "mcp-trends-hub@1.7.0"],
      "env": { "TRENDS_HUB_HIDDEN_FIELDS": "cover" }
    }
  }
}
```

几点说明：

- `cmd /c npx` 这种写法，是照你电脑上已经在用的 tavily-mcp 的写法。官方文档的通用写法是 `claude mcp add [选项] <名字> -- <命令>`。
- `@1.7.0` 是把版本钉死，防止作者以后推更新时悄悄改行为。
- `TRENDS_HUB_HIDDEN_FIELDS=cover` 是 README 里的可选项，用来去掉封面图链接，省 token。
- 写进 `.mcp.json` 的（project 范围）服务器，官方文档说第一次用时 Claude Code 会弹窗让你批准。
- README 要求 Node.js 22 或更新；你电脑上是 v22.18.0，够用。

备选（如果 trends-hub 的抖音不灵）：NewsNow 的 MCP。

```json
"newsnow": {
  "command": "cmd",
  "args": ["/c", "npx", "-y", "newsnow-mcp-server@0.0.12"],
  "env": { "BASE_URL": "https://newsnow.busiyi.world" }
}
```

它依赖作者个人的服务器，TrendRadar 的作者也提醒过这是靠人家的善意，别调用太频繁。
