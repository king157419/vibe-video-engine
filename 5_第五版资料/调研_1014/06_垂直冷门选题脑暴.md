## 一句话结论

这个月最好蹭的是两个「整月都有」的节点：**英雄联盟 S16（10-15 到 11-14）** 和 **梵高《盛放的栗树》拍卖（11-18，估价约 1.8 亿美元，现纪录约 1.172 亿；香港预展 10-13 到 10-15，首日数百人排队）**。瓦罗兰特冠军赛 10-18 就在上海决赛，但只剩 4 天，来不及专门赶。
18 个候选里排前三的是：
1. 《五打四》：兰彻斯特平方律（1916）。5 打 4，理想模型里多的一方能剩 3 个人，不是 1 个。瓦罗兰特、英雄联盟、王者荣耀三个圈子都能用。

开头 10 秒最强、真正在观众身上发生的是：**闪光滞后**（观众亲眼看到错位）、**耳虫**（观众自己在脑子里补完最后一个音）、**听声辨位**（戴耳机时观众分不清前后）。

## 0. 先回答用户问的两个词

### 0.1 瓦罗兰特玩家说的「微调」是什么

| 用法 | 意思 | 依据 |
|---|---|---|
| **最常见** | 瞄准的最后一下：先甩枪或拉枪到敌人附近，再用很小的鼠标移动，把准星挪到头上 | 游民星空攻略（2023-11-28）：「通过微调技巧」可以把准星对准敌方头部；不会的话只靠拉枪，收益很低。[链接](https://www.gamersky.com/handbook/202311/1676694.shtml) |
| 次要（未核实） | 调准星的参数（内线长度、粗细、偏移），或者调灵敏度 | 一篇瓦罗兰特技巧文章说可按分辨率对准星「做微调」。只看过搜索摘要，核查时原页打不开（链接见文末核实记录） |
| 梗 | 没查到「微调」有专门的梗 | 两次搜索都没找到（未核实） |

**结论**：中文社区没有统一定义。按攻略的用法，「微调」= 瞄准的第二段，也就是修正那一段。这正好对上运动控制里一个有名字的想法：**伍德沃斯（Woodworth）1899 年的两段式瞄准**——先一个大的「冲」，再靠眼睛看着一点点修。详见候选 #3。

### 0.2 「歌词放映」是什么

- 没查到这个词的定义，也没查到专门报道（两次搜索，未核实）。
- 最可能指的是两类东西：①全屏、逐字发光的歌词动画；②歌词卡片配歌的视频。13 号调研发现，**Folia**（一个开源的全屏逐字歌词播放器）这几周在技术圈很火，GitHub 上约 6,290 星（10-14 GitHub API 读数；仓库 2025-11-28 建立）。用户说的「歌词放映」很可能就是这类画面（推测）。
- **版权红线**：我们不能放别人的歌词，也不能放别人的旋律。能借的只有「逐字发光」这个视觉形式。内容讲「歌的科学」，声音全用我们自己的代码合成（候选 #6、#12、#14–#17）。
- 建议：请用户发一条他说的「歌词放映」视频链接，我们再对准。

### 5.1 #1《五打四》：兰彻斯特平方律

| 项目 | 内容 |
|---|---|
| 受众 | 瓦罗兰特（端游同时在线破 200 万，手游日活破千万）、英雄联盟（S16 进行中）、王者荣耀（日活超 1 亿，2020 年数据）。三个都是 5 对 5，「多一个人」是每局都碰到的事 |
| 有名字的想法 | 兰彻斯特（Lanchester）和奥西波夫（Osipov）在 1915–1916 年各自独立提出。**线性律**：一对一肉搏，最后剩下的人数 = 两边人数之差。**平方律**：人人都能瞄准、能集火时，战斗力和人数的**平方**成正比。[维基百科](https://en.wikipedia.org/wiki/Lanchester%27s_laws) |
| 讲透的数字 | 5 打 4：线性律只剩 1 人；平方律剩 √(25−16) = **3 人**。用对比说：「多一个人，最后多剩两个。」 |
| 我们自己算的 | 用 Python 随机模拟了 2 万局（本调研算的，不是论文数字）：①人人同时开火的版本（每回合每人有 2% 机会打倒一个敌人），5 人方赢 71%，赢的时候平均剩 3.6 人；②排队单挑的版本（一次只打一对，各 50%），5 人方赢 64%（精确值 163/256），赢的时候平均剩 **2.7 人**。原稿写「平均剩 1.7 人」是把输的局也算成 0 人后的总平均，和①的「赢时 3.6」不是一回事，已改。要比就同口径比：赢时 3.6 对 2.7，或总平均 2.55 对 1.73。片子里可以说「代码真打了两万局」 |
| 研究出处，可当升尺度 | 维基的写法是：一项研究（对象是澳洲肉蚁和阿根廷蚁）支持平方律，没说是这两种蚁互相打；另一项火蚁研究不支持；黑猩猩上的应用「比较成功」；也被用来建模 1863 年皮克特冲锋、1940 年不列颠空战、库尔斯克会战。[维基百科](https://en.wikipedia.org/wiki/Lanchester%27s_laws) |
| 开头 10 秒 | 0:00 黑底，左边 5 颗金光，右边 4 颗蓝光，互相射细光线。0:03 字幕：「多一个人。」0:08 打完，金光剩 3 颗，定住，硬静音。字幕：「不是剩一个。」★★：观众「应该剩一个」的直觉被打破，打仗本身就是演示。比「只问一个问题」强，但比闪光滞后弱 |
| 醍醐灌顶那一下 | 人数不是加法，是平方：5 个人是 25 份，4 个人是 16 份，差的是 9 份，不是 1 份。所以团战前先拿一个人头那么值钱 |
| 反转（满屏奇观） | 平方律只在「人人都能同时打到人人」时成立。如果地形逼着大家一个一个上（窄口、单挑），平方又退回减法。满屏奇观：几千颗光点的大会战，人少的一方像雪崩一样塌；然后同一批光点挤进一条窄缝，变成一对一，局面突然拉平。「以少打多唯一的办法：别让他们同时开枪。」（这是从模型推出来的，不是游戏数据，片子里要说清） |
| 引用 | 《孙子兵法·虚实》「我专为一，敌分为十，是以十攻其一也」。讲集中兵力，范围和平方律一样大。维基文库本原文是「我專為一，敵分為十，是以十攻其一也」，和这里一致（[维基文库](https://zh.wikisource.org/wiki/孫子兵法)）；原稿说别的版本作「十共其一」（未核实），字幕用维基文库这一版 |
| 为什么 10 月 | S16 从 10-15 到 11-14，团战天天有；瓦冠军赛 10-18 在上海决赛 |
| 风险 | IP：不用英雄、特工、地图、Logo、游戏音效，全是光点。事实：真实比赛里 5v4 的胜率没查到，**不能说「游戏里就是剩 3 个」**，只能说「理想模型」 |

### 5.2 #2《星空里的风》：梵高与湍流

| 项目 | 内容 |
|---|---|
| 受众和热点 | 艺术爱好者、梵高粉、物理爱好者。新闻热点：苏富比 11-18 纽约拍卖梵高《盛放的栗树》，估价 1.8 亿美元，可能破成交价纪录（现纪录约 1.172 亿，2022 年）。香港预展 10-13 到 10-15，首日数百人排队（法新社）。抖音热度未核实 |
| 有名字的想法 | 柯尔莫哥洛夫 1941 年的湍流理论（常叫 K41）：大旋涡把能量一级级传给小旋涡，能量随尺度的分布有固定斜率 −5/3（年份见 [维基百科](https://en.wikipedia.org/wiki/Kolmogorov_microscales)） |
| 研究出处 | 马寅翔、程婉婷、黄世迪、Schmitt、林鑫、黄永祥，《梵高〈星月夜〉里隐藏的湍流》，《流体物理》（Physics of Fluids）36 卷 9 期 095140，2024。他们分析了画里**所有**旋涡：亮度的频谱出现「−5/3 的柯尔莫哥洛夫型幂律」；比最小旋涡更小的尺度上，又出现另一种（巴彻勒型）规律。[arXiv 页](https://arxiv.org/abs/2310.03415v2) |
| 科学争议（可当反转） | 论文引言列了之前三篇：Aragón 等 2008 年发现画里亮度有湍流式的尺度不变性；Beattie 和 Kriel 2019 年算出频谱斜率接近 −2（他们用可压缩湍流解释）；Finlay 2020 年算出接近 −1，论文题目说它不符合湍流「惯性区」的标度律。2024 这篇说，几篇结果互相矛盾，主要因为都只分析了画的一部分；它把全部旋涡都算进去，才得到 −5/3。[arXiv 全文](https://arxiv.org/html/2310.03415v2)。作者猜梵高可能是观察过云和大气，或者靠天生的直觉，到底怎么做到的还说不清。[ScienceAlert 2024-09-18](https://www.sciencealert.com/this-famous-van-gogh-painting-features-astonishingly-accurate-physics)。（原稿写的「2006 年第一篇说是完美的湍流」没查到出处，已删） |
| 讲透的数字 | 《星月夜》画于 1889 年 6 月（[维基百科](https://en.wikipedia.org/wiki/The_Starry_Night)），柯尔莫哥洛夫的理论在 1941 年（[维基百科](https://en.wikipedia.org/wiki/Kolmogorov_microscales)）：**画比公式早了 52 年**。只说这一个对比 |
| 开头 10 秒 | 0:00 一杯黑咖啡，倒进一缕奶（金光）。光流卷成大旋涡，大旋涡碎成小旋涡（代码真跑流场或噪声场）。0:07 镜头拉远，这些旋涡正好拼成《星月夜》天空的构图。观众自己认出来：「这是星空。」★★（「认出来」发生在观众身上） |
| 醍醐灌顶那一下 | 大旋涡把力气传给小旋涡，每一级多大、多亮有固定比例。梵高用眼睛和手画出了这个比例 |
| 升尺度 | 一杯咖啡 → 一幅画 → 天上的云和大气 → 整片星系里的气体（后两步具体是否 −5/3，用前要查） |
| 引用 | 《庄子·齐物论》「夫大块噫气，其名为风」：大地吐的气叫风。范围是天地间所有的气流，比湍流还大，合适 |
| 为什么 10 月 | 拍卖在 11-18，之前一个月会一直有新闻；香港预展 10-13 到 10-15，今天正在展；这批拍品后面还有巴黎 10-19—23、纽约 11-07—17 两站（梵高这幅是不是每站都去，未核实）。09 号建议越快越好。建议 11-10 前发 |
| 风险 | 梵高 1890 年去世，画作本身是公有领域；但博物馆的照片可能有权利，所以我们**用代码重画构图，不贴照片**。不要讲「因为他精神病才画出湍流」，这种说法是对早期研究的过度解读，而且敏感。抖音热度没确认，发之前用抖音热点宝看一眼「梵高」的曲线 |

### 5.4 #4《你看到的是过去》：闪光滞后

### 5.5 #5《手感》：热手谬误和它的反转

### 5.6 #6《余音》：耳虫

| 项目 | 内容 |
|---|---|
| 受众 | 所有听歌的人，不集中。好处是能借 Folia「逐字发光歌词」的视觉热度（13 号），又不碰歌词 |
| 有名字的想法 | 耳虫（earworm），学名「不自主音乐表象」（involuntary musical imagery，意思是没想听，脑子里自己在放）。[维基百科](https://en.wikipedia.org/wiki/Earworm) |

### 5.7 #7《声东击西》：听声辨位

| 项目 | 内容 |
|---|---|
| 受众 | 所有 FPS 玩家：瓦罗兰特、CS2、三角洲行动、和平精英（后两个的人数未核实）。「听脚步」是 FPS 第一技能 |
| 有名字的想法 | 瑞利勋爵（Lord Rayleigh）1907 年的「双重理论」：低频靠两只耳朵的**时间差**，高频靠两只耳朵的**音量差**。人头两耳最大时间差约 626 微秒（不到千分之一秒），人能分辨 10 微秒以下的差。正前方能分辨约 1 度，侧面差得多。[维基百科](https://en.wikipedia.org/wiki/Sound_localization) |
| 关键一点 | 前后对称的两个位置，时间差和音量差**完全一样**，只靠两只耳朵分不清前后（常叫「混淆锥」）。分前后靠的是耳廓的形状：它对不同方向的声音像一个不同的「滤镜」，这个滤镜叫 HRTF（头相关传递函数）。[维基百科](https://en.wikipedia.org/wiki/Sound_localization) |
| 开头 10 秒 | 第一帧：「戴上耳机。」一个用 numpy 合成的脚步声，只用时间差和音量差，从左边绕到身后再到前面；画面上是一圈光环，一颗光点代表声音。0:06 光点消失只剩声音，字幕：「它在你前面，还是后面？」再亮：前后两个位置同时亮起——对你的两只耳朵来说，它们一模一样。★★★（但前提是戴耳机） |
| 醍醐灌顶那一下 | 两只耳朵只能告诉你「偏左多少」，分不清前后；分前后靠的是耳朵边上那块软骨 |
| 反转 | 游戏里「前后听反」不是你耳朵差，是物理。我们的合成器正好只用了时间差和音量差，所以这部片的声音本身就是证据（形式即内容） |
| 引用 | 成语「声东击西」，出处一般说是唐代《通典》卷一百五十三《兵六》，原句作「声言击东，其实击西」。这只来自二手文章，没对过原书（未核实），用前核对原文 |
| 为什么 10 月 | FPS 赛事集中；没有专属节点 |
| 风险 | 很多人用手机外放看抖音（比例未核实），不戴耳机就没效果，开头会掉人。瓦罗兰特有 HRTF 选项，但哪个版本加的没查到（未核实），不要报版本号 |

### 5.8 #8《再来一发》：可变比率强化

| 项目 | 内容 |

| 引用 | 《论语·子罕》「欲罢不能」。范围普遍 |
| 为什么 10 月 | 原神 2026 年 8 月已经到 7.0 版（[维基百科](https://en.wikipedia.org/wiki/Genshin_Impact)）；10 月有没有新版本未核实 |

## 7. 我们这个片型怎么蹭热点、快速起号（建议，不是验证过的数据）

1. **热点当门，大想法当房间。** 标题和封面的前几个字放圈内词（「5 打 4」「微调」「梵高」「S16」），片子讲的仍然是一个有名字的大想法。和 09 号的建议一致。
2. **挑「还有 10 天以上」的节点。** 冠军赛 10-18 只剩 4 天，来不及。S16 到 11-14、梵高拍卖 11-18、NBA 整个赛季，时间都够。
3. **标题用「圈内词 + 反直觉的对比」**，比如：
   - 「5 打 4，为什么最后剩 3 个？」
   - 「最后两个像素，和前面五百个一样难」
   - 「梵高比物理学家早 52 年画出了湍流」
4. **第一帧就是演示**，不放片头和 Logo。垂直圈子的人看到熟悉的场景（5v4、甩枪、星空）会停下来。
5. **每个圈子只用光点画，不用官方素材**：不用游戏画面、角色、地图、Logo、音效，不用歌词和别人的旋律，不贴博物馆照片。
6. **评论区留一个圈内问题**：「你打过最离谱的一次 4 打 5 是什么？」垂直圈子的人会在评论区自己吵起来（推测，未验证）。
7. **一部垂直、一部普适交替发**（09 号的建议）：垂直题容易拿到精准观众，普适题天花板高。
