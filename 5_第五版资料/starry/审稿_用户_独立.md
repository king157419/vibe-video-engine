# 《星空的风》独立审稿：用户视角

审阅时间：2026-10-26。审稿人未参与写稿。已读执行计划第 1–9 节及五份用户 memory；本轮依据现行 `timeline.py`，同时对照 `剧本.md`。尚未审成片。

结论：**P0 0 项，P1 3 项，P2 2 项；改完 P1 再通过。** 代码画的奶涡与星空能让现象先发生；人物日期没有被用来证明疾病造就湍流。但“生平”和“规律”目前有接缝，核心斜率仍像突然报一个名词。

## P1：必须修改

1. **94.8–110.3 秒，传记进入机制缺一句清楚的连接。** “村庄、柏树、星光，被放进同一片蓝”后突然变成“杯里的旋涡，也在做一件事”。为什么讲完梵高要回到咖啡，观众只能等着猜。可执行改法：将 104–109.5 秒改为“画里的旋涡，让人想到真实的流动”，同时把画中同一个大涡形变回开头杯里的大涡；下一句再讲能量传递。此处只能说“想到”，不能说画中真的有能量级串。这样传记留下具体画作，机制从这幅画上的具体形状生长出来。

2. **129.8–166.2 秒，−5/3 没有先教清，就被用来制造相合。** “在一定尺度里，能量谱有共同的斜率”没有告诉普通观众横轴、纵轴分别是什么；到“亮度谱，符合负五分之三的规律”才第一次报数，惊奇容易只剩权威感。可执行改法：在 129.8 秒这句，用白话说明“把旋涡按大小分开，能量的分布有规律”，屏幕给两端大小涡及同色能量线，随后出现 −5/3；在画作测量段明确“这次换成画面的明暗”，再让同一条斜率回到画面。可以拆现有一句或挪用“纳入画中全部旋涡”一句，禁止仅多加坐标和公式。能量谱示意与亮度谱示意须分别标明量的对象，避免图形重合被误读为两者等价。

3. **当前 `剧本.md` 与 `timeline.py` 已不是同一版。** 文稿仍称 240 秒、6 章，脚本为 242 秒、7 章；首句、人物段、静音前句及尾卡时间均有差异。必须由生成脚本重建文稿，再核字幕和时间点；否则用户拿审稿/交付说明找镜头会对不上。不要手改两份来维持同步。

## P2：可改善

1. **167–173.5 秒：“相遇的是统计”偏翻译腔和抽象造句。** 建议改为“画早了五十二年；相同的是一条统计规律”。保留后面“同一条斜率，不等于同一种物理过程”的限制。数字 52 需直接画两年份之间的差，不能只让人自己做减法。

2. **220.8–226.8 秒：“都值得多看一会儿”落点较轻。** 不必增加苦难或天才神话。可用更贴合这部片的“他留下笔触，后来的人还在换着方法看”，并将奶光回环留给画面；也可保留原句，优先做好第一个 P1 的连接。不能把科学论文写成画家早已懂流体公式的证据。

## 保留项与验收

- 前五秒已有亮奶光和流动，三秒出现小涡即可形成直接体验；不需要观众先猜名画。成片须检查小涡是从大涡内长出，不能只是多画几个互不相关的圆。
- 传记保留 1880、1888、1889、1890 四个节点即可，不必为“人物生平”加死因、病情或拍卖神话。
- 180 秒后的“画布里没有风速计”“同一条斜率，不等于同一种物理过程”限制有效，必须保留。
- 拍卖尾卡已区分媒体估价与成交价，独立事实核查确认时点后再交付；不应把尚未落槌的价格写成结果。
