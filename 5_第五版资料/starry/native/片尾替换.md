# 《星空的风》片尾替换

native版242秒。最后10秒为232–242：报价卡232–240，最后2秒只署名。报价是媒体估价，尚非成交价。纽约11月18日是场次日期，不是落槌时刻。

修改资料目录native/timeline.py中meta.auction.value（例如“1.XX亿美元”），label改“成交价”，生成一次JSON；Video.tsx已经读取meta.auction.label。正式发布前应核对含佣金/不含佣金口径。不要手改meta JSON。

在video-engine运行（TEMP/TMP=D:/tmp/v4starry-native）：

```powershell
& 'D:\conda\envs\d2l\python.exe' -X utf8 '..\5_第五版资料\starry\native\timeline.py'
node_modules\.bin\remotion.cmd render src\v4\starry\native\index.ts V4Starry out\v4\starry\native\tail_new.mp4 --frames=6960-7259 --concurrency=5 --muted
```

只改价格无需重新合成music/mix。拼接时沿用整条mix.wav。不能随意在原H.264的232秒处copy裁切，因为那里未必是关键帧；先把原版前232秒重新编码成一个可长期复用的head232.mp4，确认6960帧。此步骤首次替换时只做一次：

```powershell
ffmpeg -y -i out\v4\starry\native\final.mp4 -t 232 -an -c:v libx264 -crf 18 -preset slow -pix_fmt yuv420p -r 30 -colorspace bt709 -color_primaries bt709 -color_trc bt709 out\v4\starry\native\head232.mp4
```

用concat清单连接head232.mp4和tail_new.mp4的视频，再映射完整mix.wav的AAC音轨；不要-shortest。完成后重新跑v4_qa、v4_stutter和ffprobe，必须7260帧、242秒、末2秒署名。拼接命令需使用绝对文件名并将清单放native输出目录，避免同名片尾误拼。未来替换仍由制作代理执行，无需用户自己编辑代码。
