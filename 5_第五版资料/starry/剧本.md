# B《星空的风》剧本

> 2026-10-26 初稿。中文由 Codex 写作（DeepSeek 重试结果由总负责人记录）。242 秒，7260 帧，30 fps。唯一来源 timeline.py；修改字幕后重跑。

开场第 0 帧有亮奶光和字幕；15–23 秒片名卡「湍流级串 · 柯尔莫哥洛夫 · 1941」。六章依次从起步、南方的光、夜空的安排走到级串、亮度统计、边界和最后的花。

颜色：钴蓝=笔触与结构，铬黄=能量与星光，奶白=咖啡与栗花。暗底、衬线双语字幕；无旁白、无外部素材。旋涡形变三次：咖啡→星空，星空→级串，花簇→奶光。所有流线为解析示意；不声称流体模拟或论文数据复现。

173.5–177 秒满屏旋涡；177–180 秒硬静音，同时主角七帧迅速压暗，只剩孤星，星尘继续移动。232–240 秒拍卖可替换卡；240–242 秒只有极小 Opus 5.5。

文化引用「夫大块噫气，其名为风」，出自《庄子·齐物论》，比湍流范围更广，只用于观看自然的感受，不作为物理证据。
