# 第四版片单：三部 vibe知识大赏 短片

> 2026-10-08。依据：`3_第三版资料\学习\类型语法.md`（12 条不变量、可变维度、自检清单）和 `诊断_参考片对比三条样片.md`。
> 用户发来的参考是电子智人《信息论 惊奇之学》，所以采用**电子智人式的系列做法**：外壳不变，每期换母题、入口游戏、叙事骨架、「形式即内容」的梗和结尾落点；材质和配色只做小步变化。
> 制作规范：`video-engine\src\v4\CONTRACT.md`。公共组件：`video-engine\src\v4\kit\`。配乐合成：`video-engine\tools\score.py`。

## 共同外壳（三部都一样）

- 近黑底，光是主角，一屏一个主角，细宋体中英双语字幕（英文灰色斜体），没有旁白，配乐是主角。
- 冷开场里先让概念自己发生一次，片名卡后置，用粒子或光聚出来。
- 章节标签很小，每章开头只露 3–4 秒。
- 每期都有一个人名 + 年份的路标，有一次升尺度，有一次大反转（配乐最强，然后硬静音），讲一次边界（引原话或典故）。
- 首尾回环，最后落一句看法。全片没有选项卡和教学话术。
- 片尾一行小字「画面、配乐与双语字幕由 Claude 用代码生成」。
- 时长 4:00–4:45，1920×1080，30 fps。

## 三部各自换什么

| | A《峰终》 | B《弱关系》 | C《赫布》 |
|---|---|---|---|
| slug / Composition | peak / V4Peak | ties / V4Ties | hebb / V4Hebb |
| 有名字的想法 | 峰终定律（Kahneman 等，1993 冰水实验；1996 结肠镜研究） | 弱关系的力量（Granovetter 1973）+ 小世界（Milgram 1967；Watts & Strogatz 1998） | 赫布定律（Hebb 1949）：一起放电的神经元会连在一起 |
| 学科 | 心理学：记忆与评价 | 社会学 / 网络科学 | 神经科学 / 学习 |
| 入口瞬间（此刻发生在观众身上，不是回忆） | 片子先放 20 秒很好听的旋律（一条金线随旋律起伏），最后半秒落在一个刺耳的错音上（score.py 的 sour）。字幕：「最后半秒，毁掉了整首曲子？」「可前面二十秒，你明明听得很享受。」这就是 Kahneman 讲过的音乐会录音的故事，现在发生在观众自己身上 | 黑暗里两千个光点，其中一个是「你」，另一个在画面最远处。问：「你和他之间，隔着几个人？」留白。答案在后面揭晓 | 片子自己做一次条件反射：前 20 秒里，每次金色光点亮起都伴随一声「叮」。重复几次后，只有「叮」，没有光点。字幕：「刚才那一声，你是不是在等一个光点？」 |
| 母题 | 一条发光的「体验线」，以及记忆留下的两个点 | 一封信（一颗沿网络跳跃的光），以及「你」那颗点 | 一颗金色光点 + 一声「叮」；后来变成草地上被踩出来的路 |
| 叙事骨架 | 按概念的几个侧面分章：编号 + 一个字 + 英文，最接近《信息论》 | 跟着一封信旅行。章节用「年份 · 地点」当路标（1929 布达佩斯 / 1967 奥马哈 / 1973 波士顿 / 1998 康奈尔 / 2022 领英），不用编号 | 一次实验 → 机制 → 化身巡礼 → 反转（不用就会被剪掉）。章节用罗马数字 I–VI 加一个字 |
| 「形式即内容」的梗 | 片尾把这部片子自己的「强度曲线」画出来，并标出它的峰和结尾：「这四分钟，你会记住哪两帧？」配乐也按峰终设计，最后一段最温暖最响 | 片中统计「这封信经过了几个人」，最后回到「你」：屏幕外看这条片的你，也只隔几个人 | 开场的「叮」就是一次条件反射；片尾最后一声「叮」，光点没有出现，把空交给观众 |
| 升尺度 | 一次冰水实验 → 一次结肠镜 → 一段婚姻、一个假期、一整个人生 | 一个人的朋友圈 → 一个国家 → 全球七十亿人，平均只隔约四步（Facebook 2011–2016 数据，待核实） | 一个突触 → 伦敦出租车司机的海马体 → 人类婴儿的突触修剪 → 一种语言、一个习惯、一个人 |
| 大反转 | 冰水实验里，多数人宁愿再受一次「更长」的苦（多出来的 30 秒只是稍微不那么冷） | 只要随手重连 1% 的线，几十步就塌缩成几步（Watts–Strogatz 模拟，代码真算） | 不只是「用了会变强」：不用的连接会被剪掉。两岁孩子的突触比成人多得多（Huttenlocher，待核实） |
| 边界 | 峰终说的是「记住的」，不是「过过的」。Kahneman 的「经验自我 vs 记忆自我」；李商隐「此情可待成追忆，只是当时已惘然」 | 弱关系带来消息，强关系带来托底（Krackhardt 1992「强关系的力量」）；太弱的关系也没用（2022 Science 领英实验呈倒 U 形，待核实） | 赫布说的是「连接怎么变」，不是「你一定会变成什么」。鲁迅「其实地上本没有路，走的人多了，也便成了路」 |
| 落点（一种看法） | 你过的是日子，记住的是结尾。（候选，作者可改） | 改变你的，常常是你不太熟的人。（候选） | 你反复做的事，正在变成你。（候选） |

## 补充要求（2026-10-08，来自 `3_第三版资料\学习\类型语法_用户视角意见.md`，同步写进 CONTRACT §2.5）

- 开场 10 秒，让观众身上真的发生一次，回忆不算。
- 有 1–2 个满屏奇观镜头，放在反转处。
- 画面一直在动，状态之间用「变成」。
- 金句每章最多一句，放章尾。
- 走概念阶梯，每章往上一级。
- 声音：低音托底，片名处最响，反转后硬静音约 1.5 秒，结尾最响。
- 不抄「X之学 / The art of」签名。
