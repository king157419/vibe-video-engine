## 做片流程

整套做法固化成了 skill「萤火」（firefly），放在 `.claude\skills\firefly\`。在这个文件夹里说「做下一期」「给我几个题」「改一下某部片」，或者直接输入 `/firefly`，都会按它来。

## 代码在哪

- vibe知识大赏第四版：`video-engine\src\v4\`，公共组件 `kit\`，制作规范 `CONTRACT.md`。配乐 `tools\score.py`，自检 `tools\v4_qa.py`。
- vibe知识大赏第三版：`video-engine\src\v3\`。
- 读书号第二版手绘引擎：`video-engine\src\whiteboard\`、`src\ep01v2\`。
- 读书号第一版五种样式：`video-engine\src\styles\`，一键出片 `tools\make.py`。
