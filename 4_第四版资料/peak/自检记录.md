# A《峰终》制作自检记录

> 2026-10-08 制作阶段。代码：`video-engine\src\v4\peak\`（入口 `index.ts`，Composition `V4Peak`，8535 帧 = 284.5 s @ 30 fps）。
> 数据只从 `public\v4\peak\{subs,cue,numbers}.json` 读（`build_timeline.py` 产出，未改动）；画面里的读数、点数、亮度、本片曲线全部由 `data.ts` 按剧本 §2.4 公式现算。
> 配乐：`tools\score.py` → `music.wav` → 两遍 loudnorm（第二遍 linear=true）→ `mix.wav`。

## 0. 结构（便于以后改）

| 文件 | 管什么 |
|---|---|
| `data.ts` | 读 json + 按剧本公式预算：旋律线 M、手、霜点、1996 两根光丝、682 颗病人点（mulberry32(682)）、28 835 天螺旋、36 颗金点（mulberry32(36)）、满屏奇观 28 835 个日子的方向/距离（hash2(k,1/2,7)）、人生线 A/B、本片曲线 F(t)（和 `intensity_curve()` 同一算法：分段常数 → ±1.5 s Hanning 卷积 → fade_in/out → silences 置 0） |
| `fx.ts` | 自用发光画笔：沿 x / 沿 y 变色变亮的多层光线（6 遍描边 + 白热芯，全部 additive）、精灵粒子、圆角框、Catmull-Rom、重采样/形变 |
| `camera.ts` | 镜头关键帧（缩放、中心、平移）+ 极慢漂移；画布用 setTransform，DOM 标签用同一组数做 CSS transform |
| `Backdrop.tsx` | kit Backdrop 的拷贝：时间由外面传入（硬静音 1.3 秒星尘、颗粒、镜头漂移一起冻住，之后续上不跳），加一层极淡点阵 |
| `fonts.ts` / `assets.ts` | 字体就绪后才画画布字；片名字形、诗句在同一张画布上采样成粒子 → 粒子和字严格对齐 |
| `scenes/s0…s6.ts`、`scenes/title.ts` | 七章 + 片名卡的画布绘制 |
| `Overlay.tsx` | 所有 DOM 字：镜头内的贴物标签、镜头外的「示意」和顶部人名年份 |

## 1. 剧本含糊处 / 和剧本不一致处，我的决定

1. **02 章烧胶片的时间**：剧本写 95.0–97.8 从左往右烧，但 96.1 的 ding 要「只剩两帧」。两者矛盾（96.1 时只烧到第 7 格）。音乐时间不能动，所以改成 94.75 起每格间隔 0.065 s、每格 0.4 s 烧完，96.15 左右正好只剩第 12、18 格，96.1 变金。
2. **03 章唱针的起点**：剧本写唱针 139.6 从 r 300 出发，但唱片 144 秒才卷出来。改成唱臂 144.4–144.9 落下，针从 r 300（144.9）匀速走到 r 90（150.85），150.85 的错音位置不变。
3. **旋律线卷成唱片**：剧本只写「卷起来，一圈圈收成唱片」。做法：143.0–144.6 把已画的那段线重采样成 220 点，形变成 2.6 圈的螺线（r 300→230）并带转；同时 26 圈纹路由外向内显出来（裁切环从外往里收）。
4. **一生的螺旋**：剧本「第 k 圈半径 30 + 5.3k」是一圈圈同心圆。为了真的是「螺旋」，半径和角度在圈内也连续增长：r = 30 + 5.3(k + j/365)，角度 = 2πj/365 + 0.21(k + j/365)。点数、圈数、最大半径（443.4）不变。
5. **人生线 B 的延伸段**：剧本 B 整体下偏 6 px，但延伸段公式在 v=0 处 y=350。为了不断开，延伸段的 6 px 偏移随 smooth(v) 收到 0，终点仍是 (1560, 430)。
6. **满屏奇观**：28 835 个点只用 1.1 px 小方块时整屏像电视雪花（第一版试过，偏灰、发闷）。改成：每颗点画成「0.07 秒前 → 现在」的一段光痕（刚亮起时最快，所以像从笔尖炸开的烟花/跃迁），最新 500 颗加光晕，底层是沿人生线和笔尖的两团大辉光（不是整屏平涂）。字幕带（y > 920）里的光痕只画最淡一档。方向、距离、easeOut 2.0 s 全按剧本公式。
7. **300 颗「一天一天」**：300 颗挤在 260 px 的尾巴上，单画会糊成一根粗白线。改成在线两侧 ±7 px 散成一条闪烁的带（每颗仍按每秒 60 颗依次点亮）。
8. **05 章推近 B 的尾巴**：剧本只给了缩放中心 (1430, 400)、1.0→1.5。只缩放的话尾巴落在画面右三分之一。加了平移关键帧，1.5 倍时把 (1430, 400) 带到画面中心偏上 (960, 470)。
9. **「+5 年」标签**：剧本 (1430, 372) 正好压在平台线上（那里线在 y≈390，光晕到 380）。挪到 (1430, 340)。
10. **卡尼曼原话**：剧本 (960, 380) 落在唱片里，唱针最内圈的裂痕 (1018, 401) 正好压在英文字上。原话那 6 秒把裂痕退到 0.07 亮度（唱片本身按剧本降到 0.12）。
11. **本片曲线的「未来」段**：剧本写「暗虚线」，自查表又说全片没有虚线。做成每 1.5 秒一颗的暗光点（k 0.25），不是虚线。
12. **06 章诗句散成粒子**：剧本诗句 243.9 收走、244.8 才散成粒子，中间是 0.8 秒压暗。做法：诗句压暗到 0.3，244.5 起换成同字号同字距采样出来的粒子（位置和 DOM 字重合），按 x 从左往右依次飞向曲线，左边的字落到曲线左段。粒子静止时和压暗的诗句一样暗，动起来才亮。
13. **问号**：kit BreathingMark 周期约 3.9 s，剧本要 3 s，自己写了一个（DOM 字 + 画布上一团呼吸的金光），68.7 缩成金点飞走。
14. **片名卡**：剧本片名 size 150。两个字中心在 960 ± 128、y 400；下方加了一枚「小旋律线」印章（母题缩到 0.36×0.2，峰、终各一粒金），再下面金色小字和极小英文。这条小线是母题本身，不是新元素。片尾片名卡不放金色小字，也不放小旋律线。
15. **片尾署名**：用笔尖化成的冰蓝光标逐字打出（17 字/秒，281.5–282.9 打完），光标在句尾呼吸；283.0–284.5 和配乐淡出一起渐黑。
16. **1996 光丝**：加了一层极淡的「曲线下面的光」（到各自基线为止），让「疼的总量」看得见；平的那根 Q 有两个最高点（第 5、9 分钟都是 6），两个都变金。
17. **记忆光点的颜色**：冷、疼的经历底色用冰白（越难受越亮），按剧本混 0.6·(1−k) 的暖金；人生用金。

## 4. 对照 vs_reference.jpg 的判断

**像同一个类型。** 暗底偏蓝、四角压暗、星尘；画面中上部一样发光的东西，细线 + 白热芯 + 光晕；底部白色细宋中文 + 灰色斜体英文、没有底框；左上角极小的章节标签；顶部一行宽字距的人名年份；片名卡是大字 + 一行金色小字 + 极小英文，由光点聚出来；一次满屏奇观，平时 97% 是暗的。两边每 10 秒一帧并排，色调、字号层级、留白比例都在一个量级。

**差在哪：**
1. **我们更空。** 参考片很多帧在主角旁边还挂着两三行很小的读数（「第 2 问」「剩余 256 种可能」、坐标刻度），细节密度 3.3% 对我们 2.2%。我们按 CONTRACT 没做刻度和计数器，所以有些帧（1:00–1:25 的计时线、1:40 两颗光点）显得只有一根线或两颗点。
2. **金色少。** 参考片的主轴（那条金色横线、693 的光圈）大量用金；我们的「经历」是冰蓝，金只留给峰、终、记忆，全片偏冷。
3. **主角偏小。** 参考片的主体常占画面宽度 70% 以上、光晕很大；我们的胶片、记忆光点、病人点相对小。
4. 参考片在大反转处是整屏雪花→宇宙背景的「换图」，我们是粒子炸开铺满，手法不同但量级相当。

## 5. 还没解决的问题

1. 手是十几个控制点的简笔线描，读得出是手，但手指之间的轮廓偏简单；前臂两条线一直伸出画面上沿。
2. 人生线 A 和 B 只差 6 px，叠在一起像一根双线的管子（剧本要求「一模一样」，没改）。
3. 本片曲线开头 1 秒是 fade_in，从 0 直上到 0.8，画出来是 x 160 处一根竖线，乍看像第二个「缺口」。这是真实数据，没有修饰。
4. 螺旋流向笔尖时，每一圈都被拉成一个环，看起来更像一个漏斗而不是「河」。
5. 188.95 的白闪 0.18 两帧，单独抽帧看是一张灰屏，播放时是一下闪光；如果用户觉得像故障，可以改成 1 帧或去掉。
6. 没有人带声音看过。响度、静音、最响段都是测出来的，听感（尤其错音「不比旋律响、错在和声」是否听得出来）要用户确认。
7. 细节密度比参考片低一截（2.2% 对 3.3%）。如果用户觉得「太空」，最省事的加法是在演示段加一两行宽字距的小读数（例如冷水段的模拟秒数），但会碰 CONTRACT「不准常驻 HUD」的边。
