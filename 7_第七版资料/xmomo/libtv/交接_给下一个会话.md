## 怎么调 Codex

```
export TEMP='D:/tmp/codex' TMP='D:/tmp/codex'; cd /d/tmp/codex/x
timeout 580 codex exec --skip-git-repo-check --ephemeral --approve-for-me -o X.out - < X.txt > X.log 2>&1
```

- 必须带 `--approve-for-me`，否则会改东西的 MCP 调用全被拒。
- `run.sh <名字>` 已封装好这一条。
- 生图：`create_node`，nodeType image，model `doubao-seedream-5-5`，params `{"quality":"2K","ratio":"16:9","count":1}`。
- 生视频：`generate_video`，model `star-video2.5`，intent generate，`startFrameNode` 填图片节点，params `{"duration":5,"ratio":"16:9","resolution":"720p","enableSound":"on","count":1}`。
- 不要用 `run_agent`（它自己决定生成多少，积分不可控）。
